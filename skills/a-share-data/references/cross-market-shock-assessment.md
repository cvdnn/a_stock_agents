# 跨市场冲击事件评估工作流

当出现重大国际事件（如韩国熔断、日本地震、美国科技股暴跌等）需要评估对A股和持仓的影响时，使用本工作流。

## 三步工作流

### 第1步：获取事件基本面

通过新闻搜索获取事件关键信息：
- 事件类型、规模、触发原因
- 相关市场/行业/标的的跌幅
- 外资流出规模
- 历史类比情况

可使用 `mcp_scrapling_get` 搜索百度新闻、新浪财经、雪球等资讯源。

### 第2步：拉取A股多维度数据（并行）

| 数据维度 | 方式 | 作用 |
|----------|------|------|
| 大盘指数 | `fetch_realtime.py --index` | 看A股整体承受力 |
| 行业板块排行 | `stock_board_industry_name_em()` + 排序 | 看领涨/领跌板块，确认传导路径 |
| 事件相关板块 | 同上 + 关键词过滤（如"半导体"） | 核心——事件直接相关的板块表现 |
| 个股行情 | `fetch_realtime.py --quote CODE` | 持仓股实时表现 |
| 资金流向 | `fetch_realtime.py --fund-flow CODE --days 5` | 验证资金是否在流出 |

**重要数据源提示**：
- `stock_board_industry_name_em()` 通过 proxy-patch → 东财链路，稳定快速
- `--boards-summary`（DangInvest API）超时率约50%，超时后改走东财板块接口
- 系统 Python 3.9 因 numpy 冲突无法使用 proxy-patch，必须用 Python >= 3.10 的 venv

### 第3步：交叉验证与结论模板

```python
评估维度 = {
    "A股大盘承受力": f"上证{上证涨跌幅}，vs 事件市场跌幅 → 判断",
    "事件相关板块表现": f"A股对应板块{板块涨跌幅}，独立/跟随/逆势",
    "持仓股影响": f"持仓股{个股涨跌幅}，所属板块{板块排名}",
    "历史类比": "类似事件A股后续表现参考"
}
```

### 历史规律参考

- **韩股对A股直接传导有限**：相关性约0.3-0.4，远低于A股与港股
- **情绪传导为主**：A股有自身主线时（医药、红利等），外部冲击往往当天消化
- **产业链传导**：半导体/存储板块受影响最大，其他板块情绪性跟随

## 实战示例：韩国熔断（2026-06-23）

事件：KOSPI跌6.3%、KOSDAQ熔断，三星电子-7%、SK海力士-8%+
原因：芯片股获利了结（年内涨幅超90%），外资净卖出2万亿韩元

A股反应：
- 上证-0.37%（极抗跌）
- 半导体设备+1.66%、模拟芯片+1.89%（独立走强）
- 医药生物+3.12%领涨（资金避险切换）
- 结论：A股承受力强，半导体走独立行情，无需恐慌

## 不要做的事

- 不要因外部熔断就建议恐慌减仓
- 不要在未拉取A股实际数据前做"关联推论"
- 不要遗漏资金面验证
