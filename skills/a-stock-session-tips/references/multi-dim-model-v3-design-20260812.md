## 6. 诚实局限性

1. **年化低于旋转模型报告**: v3实测+39.3% vs +52.1%, 差12.8pp。来源: v3叠加跟踪止盈(减回撤但也减收益)+健康度门控。但回撤39.4%→31.6%是真实改进。
2. **方向超额为负(-4.8pp)**: 回测简化版评分精度不如完整模型; 旋转模型报告+2.2pp来自完整评分。
3. **资金维度仍是L1代理**: 资金6指标使用价格/量代理, 非真实Level-2/北向/龙虎榜。
4. **单一样本窗口**: 521日主要上升趋势市场(2024.12-2026.08), 样本外OOS验证仍需做。
5. **2仓利用率>100%**: 统计口径(2仓×持仓日/交易日), 非实际加杠杆。


### 旋转回测引擎关键设计

- 门控: 上证close>MA20时才允许做多(每日检查)
- 评分: 简化版5维(mini版, 回测中不是完整Python模型)
- 入场: 门控开+合格(close>MA20且MA5>MA10)→按综合分排序→满仓Top1
- 离场: 破MA15 / 门控关 / 跟踪止盈(最高价回落3%) / 时间止盈(5日未达+5%且有更强主线) / 旋转(高出15分新主线)
- 组合分散: num_positions=2时同时持有2只, 等分资金
