## 一、量比（Volume Ratio）— 衡量成交量异常的指标
## ════════════════════════════════════════════════

### 定义

> **量比 = 当前每分钟平均成交量 ÷ 过去5日每分钟平均成交量**

### 数值解读

| 量比 | 含义 | 盘面信号 | 案例 |
|:----:|:-----|:---------|:-----|
| **< 0.5** | **极端缩量** | 无人关注、交投冷清、地量 | 许继7/16量比0.46（磨底信号） |
| **0.5 ~ 0.8** | **明显缩量** | 买卖双方都在观望，多空平衡 | 许继7/15量比0.75 |
| **0.8 ~ 1.2** | **正常水平** | 正常交易，与5日均量持平 | 多数日常交易 |
| **1.2 ~ 2.0** | **温和放量** | 关注度提升，可能有资金开始介入 | 7/17上午许继量比~1.8 |
| **2.0 ~ 3.0** | **明显放量** | 有大资金异动，需密切关注 | 🔥 **重要信号** |
| **3.0 ~ 5.0** | **巨量** | 重大事件驱动，趋势可能反转 | 🔥🔥 许继7/17全天量比**3.6** |
| **> 5.0** | **天量** | 极端情况，利好/利空出尽 | 极少出现 |

### 实战应用原则

```
量比的解读必须结合K线形态：
  ✅ 低位+放量(量比>2)+收阳 = 底部启动（如许继7/17）
  ✅ 突破+放量(量比>2)+站上均线 = 突破确认
  ❌ 高位+放量(量比>3)+收阴 = 出货
  ❌ 高位+放量+长上影线 = 主力派发
  ⚠️ 超低位+地量(量比<0.5) = 磨底后期，即将变盘（许继7/16）
```

## 二、委比（Order Book Ratio）— 买方/卖方挂单力量对比
## ════════════════════════════════════════════════

### 定义

> **委比 = (委买手数 - 委卖手数) ÷ (委买手数 + 委卖手数) × 100%**
> **取值范围：-100% ~ +100%**

### 数值解读

| 委比 | 含义 | 解读 |
|:----:|:-----|:-----|
| **+100%** | 只有买盘没有卖盘（涨停封单） | 涨停板，多头绝对控盘 |
| **+50%~+100%** | 买盘显著多于卖盘 | 主动买盘强劲，市场看多 |
| **+20%~+50%** | 买盘略多于卖盘 | 温和看多 |
| **-20%~+20%** | 买卖平衡 | 多空僵持，方向不明 |
| **-50%~-20%** | 卖盘略多于买盘 | 温和看空 |
| **-100%~-50%** | 卖盘显著多于买盘 | 卖压沉重，市场看空 |
| **-100%** | 只有卖盘没有买盘（跌停封单） | 跌停板，空头绝对控盘 |

### 重要局限 ⚠️

> **委比只看"挂单"不看"成交"，容易被主力利用：**
> - 主力可以用大买单挂上 → 委比变+80% → 散户以为买盘强劲 → 实际主力在撤单反手卖出
> - 盘中委比大起大落是主力对倒的常见手法
> - **委比是"意向"指标，不是"行动"指标**

### 正确用法

```
委比 ✚ 外盘比（已成交数据）一起看：

  ✅ 委比+80% + 外盘比>55% = 真实买盘强劲（双重确认）
  ❌ 委比+80% + 外盘比<45% = 主力挂单诱多（虚假繁荣）
  ✅ 委比-60% + 外盘比<40% = 真实卖盘沉重
  ❌ 委比-60% + 外盘比>55% = 主力压盘吸筹（暗中在买）
```

## 三、换手率（Turnover Rate）— 衡量交投活跃度的核心指标
## ════════════════════════════════════════════════

### 定义

> **换手率 = 当日成交量 ÷ 流通股本 × 100%**
> 表示有多少比例的流通股在当天被换手

### 数值解读（A股经验值）

| 换手率 | 含义 | A股典型场景 |
|:------:|:-----|:-----------|
| **< 0.5%** | **超低换手** | 大盘蓝筹日常水平（茅台、四大行），无人交易 |
| **0.5% ~ 1%** | **低换手** | 正常交易水平，无明显异动 |
| **1% ~ 3%** | **正常~活跃** | 中小盘股日常水平，有正常资金关注 |
| **3% ~ 5%** | **显著活跃** | 有主力活动，市场关注度高 |
| **5% ~ 10%** | **高度活跃** | 热门股/短线炒作标的 |
| **10% ~ 20%** | **极度活跃** | 妖股/次新股/游资炒作高峰 |
| **> 20%** | **天量换手** | 极端情况，面临变盘 |

### 换手率分析框架

```
换手率 + 价格位置 = 判断主力意图

🔵 底部区域：
  持续低换手(<1%) + 价格横盘 = 磨底中，散户割肉离场
  突然放量(>3%) + 价格大涨 = 主力进场建仓（如许继7/17换手3.62%→底部启动信号）

🟡 中部区域：
  正常换手(1-3%) + 震荡上行 = 趋势健康，筹码交换良好
  缩量上行(<1%) + 慢涨 = 筹码锁定好，主力控盘强

🔴 高位区域：
  高位放量(>5%) + 滞涨 = 主力可能出货
  高位缩量(<1%) + 横盘 = 高位换手不足，警惕下跌

🔥 异动换手（关键信号）：
  持续3天以上换手>3% = 有大资金深度参与
  换手从<1%突然跳升至>3% = 变盘前兆（许继7/17：0.25%→3.62%🔥）
```

### 不同市值的换手率基准

| 市值区间 | 低换手 | 正常 | 活跃 | 极高 |
|:--------:|:------:|:----:|:----:|:----:|
| >1000亿（大盘） | <0.3% | 0.3-0.8% | 0.8-1.5% | >1.5% |
| 200~1000亿（中盘） | <0.5% | 0.5-2% | 2-4% | >4% |
| 50~200亿（小盘） | <1% | 1-3% | 3-6% | >6% |
| <50亿（微盘） | <2% | 2-5% | 5-10% | >10% |

> **许继电气(市值216亿)属于中盘股，正常换手0.5-2%，7/17的3.62%属于"显著活跃"级别。**
> **科大讯飞(市值975亿)属于大盘股，正常换手0.3-0.8%，当前2.43%属于"高度活跃"（减仓/异动信号）。**

## 四、内外盘（External/Internal Orders）— 主动性买卖盘判断
## ════════════════════════════════════════════════

### 定义

| 维度 | 外盘（主动买盘） | 内盘（主动卖盘） |
|:----|:----------------|:----------------|
| **含义** | 以**卖一价及以上**成交的买单 | 以**买一价及以下**成交的卖单 |
| **本质** | **买方主动出击**，吃掉挂单 | **卖方主动出逃**，砸给挂单 |
| **颜色** | 🟢 **红色/绿色**（红色数字） | 🔴 绿色/蓝色（绿色数字） |

### 核心解读

```
外盘占比 = 外盘 ÷ (外盘 + 内盘) × 100%

> 55%  = 买方主导 ✅ 主动买盘更多，市场看好
50-55% = 买盘略多，温和看多
45-50% = 卖盘略多，温和看空
< 45%  = 卖方主导 ❌ 主动卖盘更多，市场看空
```

### 实战应用（高级）

#### 1️⃣ 量价配合判断

```
外盘比 > 55% + 股价上涨 = ✅ 真实资金流入，上涨有效
外盘比 < 45% + 股价上涨 = ⚠️ 缩量拉抬，诱多嫌疑（主力用少量资金拉升，暗中出货）

外盘比 < 45% + 股价下跌 = ✅ 真实资金流出，下跌真实
外盘比 > 55% + 股价下跌 = ⚠️ 低开洗盘或主力暗中吸筹
```

#### 2️⃣ 许继电气7/17实战案例

| 时间 | 外盘/内盘 | 外盘比 | 股价 | 解读 |
|:----:|:---------:|:------:|:----:|:-----|
| 13:33盘中 | 175,279/114,103 | **60.6%** | 20.75 | 买方主动买入为主 |
| **15:00收盘** | **217,424/148,799** | **59.4%** | 20.82 | 🔥 **全天买方主导，且尾盘继续放量推高** |

> **7/17许继电气全天外盘比59.4%意味着：全天交易的每100手股票中，约59手是买方主动吃掉的，只有41手是卖方主动砸的。在大盘暴跌日出现这种结构，是非常强烈的买入信号。**

#### 3️⃣ 今日（7/20）许继与外盘比变化

| 时间 | 外盘比 | 股价 | 解读 |
|:----:|:------:|:----:|:-----|
| 9:30开盘 | **~15%** | 20.80 | 开盘卖盘占85%，获利回吐 |
| 9:40 | **~43%** | 20.80 | 逐渐恢复 |
| 10:30 | **51.3%** | 21.05 | 买卖均衡，买方略多 ✅ |
| 10:40 | **54.7%** | 21.22 | **买方主导，突破MA20确认** ✅ |

> **9:30的15%极低外盘比是典型的"周五抄底获利者开盘卖出"，随后随着买方进场，外盘比逐步回升至50%+，说明真正的资金方向是买入而非卖出。**

#### 4️⃣ 科大讯飞 vs 大盘对比

| 品种 | 外盘比 | 今日涨跌 | 解读 |
|:----|:------:|:--------:|:-----|

## 五、振幅（Amplitude）— 衡量日内波动烈度
## ════════════════════════════════════════════════

### 定义

> **振幅 = (当日最高价 - 当日最低价) ÷ 前收盘价 × 100%**
> 反映该股当天的价格波动烈度。

### 数值解读

| 振幅 | 含义 | 解读 |
|:----:|:-----|:-----|
| **< 1%** | 极窄幅震荡 | 交投沉闷，方向不明 |
| **1% ~ 2%** | 正常波动 | 大多数股票的日常波动 |
| **2% ~ 4%** | 活跃波动 | 多空存在分歧，方向即将选择 |
| **4% ~ 6%** | 大幅波动 | **重大分歧日，有资金激烈博弈** |
| **> 6%** | 极端波动 | 极度分歧/重大消息驱动/趋势反转日 |

### 实例

| 案例 | 振幅 | 含义 |
|:----|:----:|:------|
| 许继7/17 | **6.67%** 🔥 | 极端波动+6.67%，当日有重大资金分歧——开盘19.85→冲21.18→收20.82 |
| 瑞芯微7/20 | **10.3%** 🔥🔥 | 极端波动，最低193→最高214，多空剧烈搏杀后多方获胜 |
| 科大讯飞7/17 | **5.5%** | 大幅波动，但以-2.07%收跌，空方胜 |

### 四维信号验证矩阵

当出现一个信号时，用其他三个信号验证：

```
举例如许继电气7/17：
  ✅ 量比 = 3.6x → 巨量信号 🔥
  ✅ 外盘比 = 59.4% → 主动买入主导 🔥
  ✅ 换手率 = 3.62% → 显著活跃 🔥
  ✅ 振幅 = 6.67% → 极端分歧后多方胜 ✅
  
  四维全确认 → 这是真实的大资金买入行为 ✅✅✅✅
```

```
举例如科大讯飞7/20：
  ❌ 外盘比 = 41.3% → 主动卖出主导（大盘反弹时反而在卖）
  ⚠️ 量比 = 0.81x → 缩量下跌
  ⚠️ 换手率 = 0.32% → 偏低（但大盘股可接受）
  ❌ 大盘+1.75%但它-1.26% → 自身极度弱势
  
  大盘反弹它不涨→外盘卖盘主导→缩量下跌 →⚠️ 个股自身估值问题，非系统性
```

## 七、常见陷阱
## ════════════════════════════════════════════════

### 陷阱1：委比幻觉

> **主力可以用大单挂单制造虚假的委比信号。** 在卖三/卖五挂大卖单→委比变负→散户恐慌卖出→主力在买一/买二悄悄吃掉。反之在买三/买五挂大买单→委比变正→散户追入→主力在卖一/卖二卖出。

**解决方法：** 始终用**外盘比（已成交）**来验证**委比（挂单）**。

### 陷阱2：换手率单日解读

> **单日高换手率(>5%)不一定就是好事。** 需要看价格位置：
> - 底部区域高换手 = 主力建仓 ✅
> - 高位高换手 = 主力出货 ❌
> - 半山腰高换手 = 主力对倒/做量 ⚠️

### 陷阱3：内外盘在涨停板/跌停板的失真

> **在涨停板上：** 只有外盘（因为没有人挂卖单），外盘比变为100%，但这是由涨停造成的假象。
> **在跌停板上：** 只有内盘（因为没有人挂买单），内盘比变为100%。

### 陷阱4：量比在开盘前30分钟失真

> **量比公式比较的是"当前分钟均量 vs 5日分钟均量"。** 开盘前5分钟（9:30-9:35）成交量通常是一天中最大的（集合竞价积聚的单子集中释放），量比很容易>3。需等开盘30分钟后的量比才有参考价值。
