# 筹码分布 (CYQ) 分析

## 数据获取

⚠️ `stock_cyq_em()` 使用东方财富数据源，**裸连已被封锁**。需要通过 `akshare-proxy-patch` 代理才能正常获取。

正确调用方式（必须先在 `import akshare` 前安装 patch）：

```python
import yaml
import akshare_proxy_patch

# 从技能配置文件读取 TOKEN
cfg = yaml.safe_load(open("scripts/config.yaml"))["proxy_patch"]
akshare_proxy_patch.install_patch(cfg["gateway"], auth_token=cfg["auth_token"], fast=True)

import akshare as ak
df = ak.stock_cyq_em(symbol="600760")
```

或通过技能包装脚本：

```bash
VENV_PY="/path/to/.venv/bin/python3"
$VENV_PY scripts/fetch_patched.py fetch_realtime.py --quote 600760 --json
```

- `symbol`：纯数字代码即可（如 `600760`），不需要市场前缀
- 返回近 90 个交易日的筹码分布日线数据
- 数据源：东方财富（通过 proxy-patch 代理网关）

## 字段详解

| 字段 | 含义 | 典型值解读 |
|------|------|-----------|
| `获利比例` | 当前价格下处于盈利状态的筹码占比（0~1） | <0.05: 极度套牢，>0.7: 大量获利 |
| `平均成本` | 所有持仓者的加权平均成本价 | 价格低于此 → 多数人套牢 |
| `90成本-低` | 去掉最高5%和最低5%筹码后的下轨价格 | 宽幅=分歧大 |
| `90成本-高` | 去掉最高5%和最低5%筹码后的上轨价格 | — |
| `90集中度` | (上轨-下轨)/(上轨+下轨) | **<0.10 高度集中**，**0.10~0.15 适中**，**>0.15 发散** |
| `70成本-低` | 去掉最高15%和最低15%筹码后的下轨（核心密集区） | 比90%区间更紧凑 |
| `70成本-高` | 核心密集区上轨 | — |
| `70集中度` | 70%区间的集中度 | 同上判断标准 |

## 筹码集中度解读

### 集中度 < 0.10（高度集中）
- **底部集中（平均成本在低位）**：主力吸筹完成，洗盘尾声，后续大概率向上突破
- **高位集中（平均成本在高位）**：主力有控盘能力，但若获利比例很高需警惕派发

### 集中度 0.10 ~ 0.15（适中）
- 正常交易状态，筹码分布较均匀
- 趋势通常延续当前方向

### 集中度 > 0.15（筹码发散）
- **高位向低位发散**：主力出货，套牢盘割肉，平均成本下移 → 典型下跌通道
- **低位向高位发散**：增量资金入场，换手活跃，可能是上涨中继

## 关键信号组合

### 卖出/回避信号
- 90集中度持续上升(>0.15) **且** 平均成本不断下移 **且** 获利比例极低(<10%)
  → 高位筹码不断下移，主力派发，**不要左侧抄底**
  
### 底部建仓信号
- 90集中度下降至<0.10 **且** 平均成本走平 **且** 价格在平均成本附近
  → 底部换手充分，筹码完成转移，**关注反转**

### 上涨趋势确认
- 获利比例>60% **且** 平均成本上移 **且** 集中度适中(<0.13)
  → 增量资金持续入场，趋势健康

## 持仓分析中的应用

在 `position-monitoring-workflow.md` 的全维数据拉取步骤中，建议加入筹码分布查询：

```python
import akshare as ak
df_cyq = ak.stock_cyq_em(symbol="600760")
latest = df_cyq.iloc[-1]
first = df_cyq.iloc[0]

analysis = {
    "获利比例": f"{latest['获利比例']*100:.1f}%",
    "平均成本": latest['平均成本'],
    "90集中度": latest['90集中度'],
    "集中度趋势": "上升发散" if latest['90集中度'] > first['90集中度'] else "收敛集中",
    "均价变化": f"{first['平均成本']} → {latest['平均成本']}",
}
```

### 解套策略中的筹码应用

- 90%成本上轨 = 强阻力位（大量套牢盘解套卖出），减仓触发价可设于此
- 70%成本区间 = 核心持仓密集区，若价格进入此区间下沿且获利比例极低，可能是最后一跌
- 平均成本持续下移 + 集中度发散 → 不要加仓，反弹减仓
- 平均成本走平 + 集中度收敛 < 0.10 → 可考虑分批介入
