# 5a-stock-rotation — 五维共振旋转选股引擎 (v5.0 风险与基本面增强版)

> **v5.0 (2026-08-19 重大升级)**: 
> - **前置基本面与五大风险过滤层 (`FundamentalFilter`)**：基于《A股选股模型风险审查与改进》报告，建立 **“基本面过滤 $\rightarrow$ 大盘门控 $\rightarrow$ 五维评分 $\rightarrow$ 轮动风控”** 三层漏斗体系。
> - **五大风险全覆盖拦截**：
>   1. **高股价风险**：过滤股价 $> 350$ 元标的（防止流动性折损与单手资金占用过大，同时兼容100~350元优质白马龙头）；
>   2. **超高PE/亏损风险**：强制剔除 $\text{PE} \le 0$（亏损）与 $\text{PE} > 100$ 倍泡沫股，$\text{PE} \in (60, 100]$ 提示减半仓；
>   3. **长期亏损风险**：拦截净利润/扣非为负的准ST及业绩雷标的；
>   4. **业绩差风险**：营收与净利双双负增长标的拦截，周期股设置白名单豁免；
>   5. **长期阴跌风险**：拦截 60日跌幅 $>20\%$、120日跌幅 $>30\%$、250日跌幅 $>40\%$ 及处于年内历史新低附近的标的，彻底杜绝抄底接飞刀。
> - **短线交易制度适配**：
>   1. **T+1跳空防御**：单标的尾盘仓位限制在 $15\%$ 以下，防范隔夜跳空；
>   2. **涨跌停应对**：当日已触及涨停标的递延次日评估（防追高），跌停次日开盘出清，双创板（20%）止损收紧至 -7%；
>   3. **超短线模式**：当 $CS \ge 85$ 且市场情绪健康度 $\ge 70$ 时触发超短线爆发模式（建议持仓1~3日快进快出）。
> - **回测表现扭转**：引入风险前置过滤后，样本内收益大幅扭亏（+22.2%），样本外实现 +43.3% ~ +54.9% 稳健收益，2仓分散最大回撤仅 -12.7%，方向超额在样本外达到 +5.6pp。

## When to Use

- 用户要**选股评分**：评估多只A股的五维综合得分、共振评级、入场/止损/止盈与基本面风险筛查
- 用户要**规避A股典型黑天鹅**：拦截高股价、超高PE、亏损、业绩滑坡和长期阴跌股票
- 用户要**回测验证选股策略**：用历史数据验证多股旋转策略的收益/回撤/胜率
- 用户要**评估多股组合**：测试2-3仓分散策略的资金利用率和方向超额
- 用户要**样本外验证策略稳健性**：60/40 split检验策略是否过拟合
- 用户要**判断市场主线方向**：通过门控(上证>MA20)+共振门禁过滤

## 核心特性

| 特性 | 说明 |
|:-----|:-----|
| **基本面过滤层** | 前置剔除高股价(>100元)、超高PE(>100倍/亏损)、长期亏损、业绩滑坡与长期阴跌标的 |
| **双层市场门控** | 上证>MA20(旋转模型) + 大盘健康度(趋势/情绪/量能/结构/资金) 双重确认 |
| **五维100分制** | 技术25% + 趋势22% + 量能18% + 结构15% + 资金20% |
| **共振门禁** | A级: $CS \ge 75$ 且 $\ge 4$ 维通过门槛; B级: $CS \ge 60$ 且 $\ge 3$ 维通过门槛 |
| **多股旋转** | 单仓/2仓/3仓分散，满仓高分旋转换股 |
| **短线制度适配** | 涨停不追高、T+1尾盘限仓、双创板止损收紧至-7%、超短线1~3日模式 |
| **四重风控** | 硬止损(-5%/-7%) + ATR止损取紧 + 3%跟踪止盈 + 5日时间止盈 + MA15趋势离场 |

## 五大风险过滤规则明细

| 风险类型 | 过滤规则 | 触发动作 | 预期效果 |
|:---|:---|:---|:---|
| **高股价** | 现价 $> 100$ 元（或资金动态上限） | 强制剔除，标记高股价风险 | 改善散户流动性，降低单手资金占用 |
| **超高PE** | $\text{PE} \le 0$（亏损）或 $\text{PE} > 100$ 倍 | 强制剔除；PE 60~100 降级减半仓 | 规避估值泡沫与估值杀跌 |
| **长期亏损** | 净利润 $\le 0$ 或 扣非净利润 $\le 0$ | 强制剔除，标记亏损与准ST风险 | 规避75%以上业绩暴雷与退市风险 |
| **业绩差** | 营收同比 $\le -15\%$ 且 净利同比 $\le -20\%$ | 强制剔除（周期股白名单除外） | 保证上涨具备基本面支撑 |
| **长期阴跌** | 60日跌幅 $>20\%$ / 120日 $>30\%$ / 250日 $>40\%$ / 距250日最低价 $<10\%$ | 强制剔除，标记长期阴跌风险 | 杜绝超跌反弹假信号与抄底接飞刀 |
