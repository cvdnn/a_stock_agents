# 监控工作流模式（经验积累）

## 模式一：全池通用入场监控

`entry_monitor.py` — 读取关注股池所有A/B级票，普适性检测。

```
- 读取 watch_pool.csv, 过滤 A/B级
- 逐只获取行情+MA
- 匹配 entry_condition 字段
- 触发后一次性提示
- 状态持久化避免重复推送
```

## 模式二：单票专项策略监控（新）

`entry_monitor_605358.py` — 为立昂微方案A定制的精细化监控。

```
- 硬编码目标价/止损/条件
- 4项条件逐条检测 + 显示满足/不满足
- 满足4/4 → 入场信号
- 满足3/4 → 接近预警
- 不满足 → 完全静默（不输出任何内容）
- 状态持久化, 每日自动重置
```

### 适用场景

当需要比通用 entry_condition 更精细的策略监控时（如指定具体价格±容差、具体K线形态），
创建单票专项脚本而不是修改通用检测器：

- **通用entry_monitor**：适合大范围扫描，条件宽松
- **专项entry_monitor**：适合精准策略入场，条件严格

## 模式三：持仓风控预警

`position_stop_monitor.py` — 多级价格预警。

```
- 每只持仓: 止损价 + 2~3层预警线
- 仅向下跌方向检测
- 红色(止损) / 橙色(接近) / 黄色(关注)
- 只触发最贴近的一条
```

## 模式四：精选候选硬编码MA20监控（新增 2026-06-29）

`entry_monitor_picks.py` — 预计算MA20并硬编码，仅腾讯API拉实时价。

## 模式五：持仓沙盘（重写后）

`sandbox.py` — 每15分钟输出持仓状态摘要。

**原版本问题**：默认输出AI模板提示，但cron是no-agent模式导致推送无用信息。

**修复方案**：
1. 默认输出实际的持仓摘要（实时价、浮盈、距止损距离）
2. 使用腾讯行情API（稳定2秒返回）替代akshare（常超时）
3. 数据获取全挂时静默退出，不推送空壳信息

## 统一规则

所有 no-agent 模式运行的 cron 脚本必须遵守：

| 原则 | 说明 |
|------|------|
| **无事件则静默** | 无事可报时输出空内容，AI-Platform不推送空消息 |
| **不得输出模板/占位符** | 禁止输出"请XX分析""等待XX处理"类文本 |
| **不得输出空壳标题** | 没有实质内容时连标题都不打印 |
| **状态持久化防重** | 同一事件同一交易日只触发一次 |
| **可读性优先** | 数据字段用竖线`|`分隔，避免换行堆砌 |

## 跳空缺口检测方法

**正确方法**：比较 `今日开盘` vs `昨收收盘`

```python
gap_up = curr_open - prev_close
```

**错误方法**：比较 `今日最低` vs `昨日最高`（盘中会填缺口）

## 韩国熔断传导链（2026-06-23案例）

```
KOSPI熔断(-4.3%) → 三星-4%/SK海力士-6%
    → A股半导体板块从+1.06%跌至-0.64%
    → 元器件板块-3.23%
    → 资金避险: 银行+2.25%/证券+1.37%
```

**影响评估**：
- A股半导体跟随下跌但幅度有限，非系统性危机
- 军工/国防板块几乎不受影响
- 纯内需/政策驱动票受影响最小
