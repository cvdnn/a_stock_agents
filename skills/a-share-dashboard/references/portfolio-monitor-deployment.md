# 全天持仓监控 + 多脚本部署模式

## 架构概述

从2026-07-21起，对单只重要持仓（如许继电气000400）部署三层监控脚本：

```
竞价分析 (09:25-09:30)       午盘分析 (11:30-12:00)       全天监控 (每5分钟)
┌──────────────────┐        ┌──────────────────┐        ┌──────────────────────┐
│ auction_000400   │ ──→    │ midday_000400    │ ──→    │ portfolio_monitor    │
│ → 竞价量价       │        │ → 半日K线数据    │        │ → 止损/止盈检测     │
│ → 主力意图评估   │        │ → 买卖盘比       │        │ → 异动提醒          │
│ → 开盘预判      │        │ → 主力资金流向   │        │ → 组合盈亏汇总      │
│ → Windows推窗    │        │ → 板块排名       │        │ → 散户思维提示      │
└──────────────────┘        └──────────────────┘        └──────────────────────┘
```

## 三个脚本在 `~/.AI-Platform/scripts/` 下

部署时脚本放在 `~/.AI-Platform/scripts/`，cron使用 `--workdir ~/.AI-Platform/scripts` 确保路径正确。

## Python 3.9 兼容性

所有cron脚本运行在 WSL 系统 Python 3.9，不支持：
- `dict[str, Any] | None`
- `list[dict] | None`
- `-> dict:`, `-> str:` 等类型注解（可以去掉，脚本内没有mypy检查）
- `from __future__ import annotations` 可以加在最顶部开启后向兼容

## 状态持久化

每个脚本维护自己的 `_state.json` 文件在 `~/.AI-Platform/scripts/` 下，关键模式：
- `triggered` 字典按 `{type}_{code}_{date}` 键存储，同一事件同一日只触发一次
- `first_run_today` 布尔值，每日重置，用于每日首次的特殊提醒
- 每天启动时清理7天前的旧记录

## 可用资金配置

`portfolio_monitor.py` 顶部有 `AVAILABLE_CASH = 40000` 常量，当资金变动时手动更新。
