## 二、batch2-decisions（已裁定，待实现）

以下 6 项均出自本计划 §六「待产品确认事项」（历史编号 §26），已于 2026-09-21 第 1 批产品裁定中逐项决策，阻塞条件解除；各条保留原问题描述与裁定结论，供实现对照。

### B1 · Web 启停权限（§26-6）

- **规范原文**：「Web 中谁有权激活策略和启停自动调度」。
- **裁定结论（D-07）**：**管理员 + 模型作者**。模型作者可激活/停用本人模型；自动调度启停归管理员。
- **影响面**：Web 端权限模型、自动调度任务的鉴权链路。

### B2 · 通知渠道（§26-7）

- **规范原文**：「信号通知渠道采用 Web 站内、桌面 Toast 还是外部消息渠道」。
- **裁定结论（D-08）**：**仅 Web 站内**；首期不引入桌面 Toast 与外部消息渠道。
- **影响面**：通知分发层（首期不外发，无需外部渠道凭据与重试策略）。

### B3 · 跨维度分数引用（§26-8）

- **规范原文**：「条件模型首期是否允许跨维度引用派生分数，还是仅允许布尔结果引用」。
- **裁定结论（D-09）**：**双轨**。默认仅允许布尔结果（`VERDICT_PASS/FAIL/UNKNOWN`）引用；若需引用派生分数，必须在规则元数据中显式声明所依赖的分数契约版本，编译期校验循环依赖。
- **影响面**：条件模型 DSL 的引用类型校验、编译期依赖图与循环引用检测、分数契约版本注册。

### B4 · 模型可见性（§26-9 / §26-10）

- **规范原文**：「用户自建模型是否默认仅本人可见，后续是否支持模板共享和复制」；「模型名称是否允许重复；建议允许显示名称重复，但 `model_id` 必须全局唯一」。
- **裁定结论（D-10）**：**默认仅本人可见**；显示名允许重复，`model_id` 全局唯一。模板共享与复制首期不做（可后续以显式分享扩展）。
- **影响面**：模型注册表可见性字段、列表查询过滤、`model_id` 唯一性约束。

### B5 · T+N 标记价口径（§26-14）

- **规范原文**：「T+N 默认使用开盘、收盘还是 VWAP 作为标记价格；建议同时保存标准口径，但模型评价固定一个主口径」。
- **裁定结论（D-14）**：**多口径存储**（收盘/开盘/最高/VWAP）；**模型评价固定收盘为主口径**。
- **影响面**：跟踪观察存储结构需支持多口径字段；模型评价与优化建议统一读取收盘口径以保证可比性。

### B6 · 评价最小样本量（§26-16）

- **规范原文**：「模型评价触发的最小样本数、最短观察周期和默认比较基准；上线前必须由研究治理规则确定」。
- **裁定结论（D-16）**：由**研究治理规则书面确定**，三项均参数可配置；默认值 样本数 ≥30、最短观察周期 ≥20 交易日、比较基准 = 沪深300。
- **影响面**：模型评价门禁与「简单优化建议」的触发条件（§26-19 要求建议可追溯到具体 `run_id` 与观察样本）；需在 `algorithm-governance.md` 落书书面规则。
