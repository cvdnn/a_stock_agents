## 一、 设计哲学与视觉基调 (Design Philosophy & Aesthetics)

本系统面向专业 A 股量化投资者与机构级投研人员，遵循 **浅色金融商务风格（Clean Light Financial Aesthetic）**：

### 1. 视觉减负与数据优先
界面不使用多余的装饰性花哨渐变，以清晰规整的网格卡片、等宽数字、高对比度核心指标呈现金融投研数据。

### 2. 涨跌色彩铁律 (A-Stock Red-Up/Green-Down Standard)
严格遵守中国 A 股交易市场标准（**红涨绿跌**）：
- **上涨 / 盈余 / 做多色**：`#F5222D`（浅底背景：`#FFF1F0`，边框：`#FFA39E`）
- **下跌 / 亏损 / 规避色**：`#52C41A`（浅底背景：`#F6FFED`，边框：`#B7EB8F`）
- **品牌主色**：`#1677FF`（深蓝，代表理性、量化与科技）
- **全局背景**：`#F8FAFD`（亚光冷白，护眼防疲劳）
- **卡片底色**：`#FFFFFF`；细分割线：`#DFE6EF`

### 3. 高精数字排版 (Tabular-nums)
涉及行情价格、涨跌幅、成交量、资金流、保本价等所有金融数值，必须强制启用 CSS `font-variant-numeric: tabular-nums`，确保垂直方向精准对齐。

### 4. 边框轻量化与卡片视觉一致性 (Subtle Border & Zero-Stripe Principle)
- **彻底摒弃粗彩色竖条**：摒弃卡片、自选列表项、快评条目及监控流左侧生硬突兀的 3px/4px 粗彩色竖条（`border-left`）；
- **统一浅色金融微边框**：全面统一采用清爽、规整的 1px 浅色金融边框（如普通卡片 `1px solid var(--border-card)` / `#EBF1F8`，高亮引用卡片 `1px solid #D6E4FF`，激活自选股采用浅蓝底色 `#EFF6FF` 替代竖条）；
- 保持金融图表与信息流界面呼吸感一致，杜绝杂乱的装饰性色块打扰交易专注度。

## 二、 工作区整体架构：双模动态视口规范 (Adaptive Dual-Mode Layout)

为兼顾“深度会话投研”与“专业业务看盘分析”两种截然不同的核心场景，工作区采用**意图驱动的双模动态视口架构（Intent-Driven Dual-Mode Viewport）**。视口高度严密锁定在 `calc(100vh - 50px)`，杜绝整页滚动。

### 1. 模式一：【投研助手】模式 (Chat-Centric Dedicated Mode)
当用户在左侧菜单栏选择 **【投研助手】**（或新建/切换历史会话）时触发：
- **【AIChatUI】居于中间核心主交互位（占 40% 宽度）**：主视觉焦点，专注于多轮投研问答、量化推演与动作单生成；该模式下 AIChatUI 始终常驻展示。
- **右侧定位为【工作台】（占 60% 宽度）**：承载整体市场盘面、快捷操作矩阵、自选股异动盯盘、策略回测看板、模拟交易资产统计及实战三原则风控核算六大板块。
- **长条连通顶部栏规范（Unified Connected Top Bar）**：
  - 顶部栏横贯中间与右侧，消除中间垂直分割线与突兀的 `[📊] 工作台` 独立标题；
  - 顶部栏左端常驻展示 `[AI] 投研助手 ● 在线`，右端常驻展示 `[收起 ▶]` 折叠按钮；
  - 垂直分割线仅在顶部栏下方的内容区域生效（区隔左侧对话流与右侧工作台盘面组件），使工作区视觉浑然一体；
- **工作台收起与展开交互闭环**：
  - **收起动作**：点击长条顶部栏右侧 `[收起 ▶]` 按钮，工作台平滑向右收起（`width: 0` / `display: none`），中间 AIChatUI 弹性扩展至 **100% 全宽**，开启沉浸式投研对话；
  - **唤回动作**：工作台收起后，长条顶部栏右侧动态展示高亮 `[📊 工作台 ◀]` 小按钮；点击该按钮即可平滑恢复为 40%/60% 双栏工作区，Canvas 图表自动重绘适配。

### 2. 模式二：【业务主工作区】模式 (Workspace-Centric Copilot Mode)
当用户在左侧菜单栏点击其他核心业务功能（如 **【市场行情】**、**【自选个股】**、**【收益分析】** 等）时自动触发：
1. **主工作区居中（占据中间主体视口，65%~100% 宽度）**：
   - 业务内容（市场行情全景看板、自选股深度研判、收益分析等）跃升为主导视重视窗；
   - 拥有独立的主工作区 Title 栏与多标签管理能力；
2. **【AIChatUI】定位为 AI 助手（伴随式 AI Copilot）并变动到右侧（390px 固定宽度）**：
   - 标题切换为 `🤖 AI助手 ● 协同中`，顶部提供 `[▶ 收起]` 按钮；
   - 支持随主工作区内容上下文同步滚动提问、参数联动修改与答疑。

## 三、 AIChatUI 界面元素设计契约 (Chat Components Contract)

### 1. 会话消息卡片流 (Message Stream Cards)
- **用户提问卡片**：浅蓝高亮底色（`#EFF6FF`），右浮动或居右视觉对齐，附带引用角标；
- **智能体回答卡片**：纯白底色（`#FFFFFF`），带 1px 细微灰蓝阴影，顶部包含智能体思考历程（Thought Process 折叠面板）；
- **思考过程卡片**：灰色虚线边框，收起时显示耗时与思考步数（如 `> 思考了 3.2s，调用了 2 个分析工具`），展开后以打字机单色弱光文字呈现推理链（COT）。

在对话流或工作台展示交易决策时，必须采用标准化三原则紧凑卡片组件：

### 3. 输入区域交互契约 (Chat Input Contract)

#### 3.1 富文本输入框与 DOM 兼容契约 (Rich Text Input & DOM Compatibility)
- **技术实现**：采用 `<div contenteditable="true">` 替代传统 `<textarea>`，以支持内嵌高亮 @token 标签节点；
- **占位提示**：通过 `data-placeholder` 属性 + CSS `::before` 伪元素实现，当输入框为空时展示提示文案（如 `请输入您的问题，或输入 @ 快速插入股票、引用、技能与算法操作符...`）；
- **尺寸约束**：最小高度 `38px`，最大高度 `120px`，溢出时自动展示垂直滚动条（`overflow-y: auto`）；
- **行为规范**：`Enter` 键直接提交（等效点击提交按钮），`Shift+Enter` 换行；
- **DOM 兼容层 (`setupChatInputCompatibility`)**：通过 `Object.defineProperty` 代理 `chatInput.value` 的 getter/setter，分别委托给 `getChatInputPlainText`（提取包含 `@名称(代码)` 的纯文本）与 `setChatInputFromText`（将文本内 `@token` 还原为内联高亮节点），确保与旧有表单处理逻辑零破坏兼容。

#### 3.2 @Token 高亮加粗标签 (At-Token Inline Badge)
- 当用户通过 @操作符浮窗选中某个条目后，在输入框光标处插入一个**不可部分编辑的原子化内联标签**（`<span class="at-token" contenteditable="false">`）；
- 标签样式：`font-weight: 700`、品牌蓝底色 `#E6F4FF`、蓝色边框 `#91CAFF`、圆角 `4px`、阴影 `0 1px 2px rgba(22,119,255,0.08)`；
- **分类色值**：
  - 股票类：`color: #0958D9; background: #E6F4FF; border: #91CAFF`
  - 自选类：`color: #D46B08; background: #FFF7E6; border: #FFD591`
  - 引用类：`color: #135200; background: #F6FFED; border: #B7EB8F`
  - 技能类：`color: #D4380D; background: #FFF2E8; border: #FFBB96`
  - 算法类：`color: #531DAB; background: #F9F0FF; border: #D3ADF7`

#### 3.3 退格原子化删除机制 (Backspace Atomic Deletion)
- @token 为**不可拆分的原子节点**：光标紧邻 @token 右侧时按 Backspace，整个标签连同其前置空格**一次性整体删除**；
- 删除后光标自动归位至前一个节点末尾（文本节点或前一个 @token 之后）；
- 多余空白文本节点自动合并清理，保持 DOM 结构整洁；
- 具备纯文本正则降级兜底机制（匹配末尾 `@token` 并原子回退）。

#### 3.4 底部微功能工具栏与现代 CSS 规范 (Input Toolbar & CSS Standards)
- 工具栏仅保留两个精简按钮：
  - **`[+] 扩展`**：预留扩展功能面板入口；
  - **`[@] 操作符`**：点击触发 @操作符浮窗（等效在输入框中键入 `@`）；
- **提交按钮**：品牌渐变蓝底色，文案为「提交」，hover 采用 `filter: brightness(1.1)` 提亮（而非切换 `background` 属性，以避免渐变背景重绘闪动）；
- **多行截断标准 CSS 属性**：所有涉及文本截断的样式必须双写标准 `line-clamp: 1` 与 `-webkit-line-clamp: 1`，消除现代浏览器 vendorPrefix 兼容性警告。

## 四、 顶部技能治理中心与通知系统 (Governance & Toast)

### 1. 技能治理中心弹窗 (Skill Governance Modal)
- 常驻于顶栏右侧工具区：`[🛡️ 技能治理]`；
- 点击弹出沉浸式治理看板，包含：
  - 17 项技能状态卡片矩阵（分类标签、版本、只读/交易权限徽标、启停开关 Switch）；
  - 动态参数调试测试终端；
  - 运行监控指标（调用量、平均响应耗时、错误率）；
  - 一键热重载（Reload Manifest）。

### 2. Toast 全局消息浮层规范
- **定位**：固定在屏幕**右下角**（`bottom: 24px; right: 24px;`）；
- **堆叠动效**：多条消息产生时向上反向堆叠（Stack Upwards），避免遮挡主操作区视线；
- **状态色彩**：成功 `#52C41A`（绿）、警告 `#FAAD14`（黄）、错误 `#F5222D`（红）、信息 `#1677FF`（蓝）。

## 五、 @操作符浮窗交互规范 (At-Operator Popup Interaction Specification)

### 1. 功能定位与触发条件
@操作符是 AIChatUI 输入区域的核心增强机制，允许用户快速引用**股票标的、历史引用、量化技能与算法模型**并嵌入到提问上下文中。
- **触发方式一**：在富文本输入框中键入 `@` 字符；
- **触发方式二**：点击底部工具栏 `[@] 操作符` 按钮；
- **关闭方式**：按 `Esc` 键、点击浮窗右上角 `×` 关闭按钮、或点击浮窗外部区域。

### 2. 浮窗定位与布局规范 (Popup Layout)
```text
┌─ input-container ────────────────────────────────────────────┐
│ ┌─ @操作符浮窗 (bottom: calc(100% + 8px), 同宽对齐) ───────┐ │
│ │ ┌─ Header ──────────────────────────────────────────────┐ │ │
│ │ │ [@] 功能操作符  股票·引用·技能·算法              [×] │ │ │
│ │ ├─ Body (250px 高度) ───────────────────────────────────┤ │ │
│ │ │ ┌─ Sidebar ─┐ ┌─ Content ────────────────────────┐   │ │ │
│ │ │ │ (120px)    │ │ [搜索框 (仅股票类别)]           │   │ │ │
│ │ │ │ · 📈 股票 ◄│ │ ┌─ 股票卡片 ─────────────────┐  │   │ │ │
│ │ │ │ · 📎 引用  │ │ │ 中芯国际(688981) [持仓 5%] │  │   │ │ │
│ │ │ │ · 🧩 技能  │ │ │ 实时:¥82.50|成本:¥80.20    │  │   │ │ │
│ │ │ │ · 🔬 算法  │ │ │ +2.87% · 半导体龙头         │  │   │ │ │
│ │ │ │            │ │ └─────────────────────────────┘  │   │ │ │
│ │ │ └────────────┘ └──────────────────────────────────┘   │ │ │
│ │ ├─ Footer ─────────────────────────────────────────────┤ │ │
│ │ │ [ESC] [▲▼] [→] [←] [↵]                               │ │ │
│ │ └───────────────────────────────────────────────────────┘ │ │
│ ├─ 富文本输入框 ─────────────────────────────────────────────┤ │
│ │ 你好 @[📈 中芯国际 688981] 请分析 █                        │ │
│ ├─ 底部工具栏 ───────────────────────────────────────────────┤ │
│ │ [+ 扩展] [@ 操作符]                              [提交]   │ │
│ └────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

- **浮窗定位**：`position: absolute; bottom: calc(100% + 8px); left: 0; right: 0;`，宽度与 `input-container` 完全同宽对齐；
- **视觉样式**：白色底色 `#FFFFFF`，`border-radius: 12px`，强阴影 `0 12px 32px -4px rgba(15,23,42,0.16)`；
- **进入动画**：`0.18s cubic-bezier(0.16, 1, 0.3, 1)` 上滑进入（`translateY(6px) → 0`），同时 `opacity: 0 → 1`。

### 3. 双栏导航与键盘交互契约 (Dual-Pane Keyboard Navigation)
浮窗分为**左侧类别菜单栏（Menu Pane）**与**右侧内容列表区（Content Pane）**，采用焦点窗格（Focus Pane）状态机控制键盘行为：

| 焦点窗格 | 按键 | 行为 |
|:---:|:---:|:---|
| 菜单栏 | `↑` / `↓` | 切换类别菜单（股票→引用→技能→算法循环），同步刷新右侧内容 |
| 菜单栏 | `→` / `Enter` | 焦点切换至右侧内容区，高亮第一个条目 |
| 菜单栏 | `Backspace` | 关闭浮窗（等效 Esc） |
| 内容区 | `↑` / `↓` | 上下移动条目高亮选中（循环），自动滚动保持可见 |
| 内容区 | `←` | 焦点切回左侧菜单栏 |
| 内容区 | `Enter` | **确认选中条目**，将 @token 回填至输入框光标处，自动关闭浮窗 |
| 任意 | `Esc` | 关闭浮窗 |

### 4. 四大操作符类别定义 (Operator Categories)

| 类别 | 图标 | 数据来源 | 条目排列规则 |
|:---:|:---:|:---|:---|
| **股票** | 📈 | AtOperatorRegistry.stock（三大股池合并） | 按【持仓→自选→关注】池优先级排列，池内按中文名称 `localeCompare('zh-Hans-CN')` 排序 |
| **引用** | 📎 | AtOperatorRegistry.ref（工作台六大板块引用） | 固定顺序 |
| **技能** | 🧩 | AtOperatorRegistry.skill（17项技能子集） | 固定顺序 |

### 5. 股票搜索过滤机制 (Stock Search Filter)

### 6. 三大股池多维展示卡片设计 (Stock Pool Cards)

#### 6.1 股票类标的卡片（三行式一体化排版）
```text
┌─────────────────────────────────────────────────────┐
│ 📈  中芯国际 (688981) [持仓 5%]                     │  ← 标题行：图标 + 名称 + 代码 + 股池胶囊徽章

│     半导体制造龙头·国产芯片替代                       │  ← 描述行：题材标签缩略
└─────────────────────────────────────────────────────┘
```

- **股池胶囊徽章 (Pool Badge)**：
  - 持仓股：**暖橙底** `background: #FFF7E6; color: #D46B08; border: 1px solid #FFD591;`，文案「持仓 xx%」（*严格规避与 A 股红涨绿跌之红色相冲突*）；
  - 自选股：**科技蓝底** `background: #EDF5FF; color: #1677FF; border: 1px solid #ADC6FF;`，文案「自选」；
  - 关注股：**紫罗兰底** `background: #F9F0FF; color: #722ED1; border: 1px solid #D3ADF7;`，文案「关注」。
- **涨跌幅标签**：遵循红涨绿跌铁律，上涨 `#F5222D` 红底、下跌 `#52C41A` 绿底、平盘 `#64748B` 灰底，带 `+`/`-` 前缀号。

#### 6.2 非股票类标的卡片（引用/技能/算法）
采用双列紧凑布局：左侧为图标+名称+描述，右侧为类型标签与勾选标识。

### 7. AtOperatorRegistry 数据注册中心 (Operator Data Registry)
`AtOperatorRegistry` 是前端全局数据注册对象（挂载于 `window.AtOperatorRegistry`），承载 @操作符浮窗的全部条目数据源。其与 A2UI `UIEngine` 组件注册中心的边界划分如下：
- **UIEngine（`web/js/ui_engine.js`）**：管理**渲染层面**的 A2UI 领域组件包注册、骨架屏调度与渲染寻址；
- **AtOperatorRegistry（`web/js/app.js`）**：管理**输入层面**的操作符条目数据（股票标的、引用、技能、算法），供 @操作符浮窗检索与回填使用。
