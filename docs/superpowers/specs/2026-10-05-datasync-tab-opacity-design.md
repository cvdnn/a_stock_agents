# 数据同步 Tab 穿透修复设计

## 目标

修复【数据同步】页面的吸顶 Tab 栏在滚动时显示下层内容的问题，同时保持现有页面布局、吸顶交互和视觉配色不变。

## 根因

基础样式已经为 `.datasync-tabs` 提供不透明背景，但数据同步页面的后置定制规则将其覆盖为 `background: transparent`。由于该容器同时使用 `position: sticky` 和较高层级，滚动内容会在它下方继续绘制，从而产生视觉穿透。

## 设计

- 保留 `position: sticky`、`top: 0` 和现有层级，不改变 Tab 的滚动行为。
- 将数据同步页面定制规则中的 Tab 容器背景改为页面背景色 `#f5f8fc`，形成完整的不透明遮罩，并与当前工作区背景保持一致。
- 不修改单个 Tab 按钮的透明背景；按钮继续继承容器底色，保留现有 hover 和选中态。
- 不引入阴影、模糊或额外边框，避免扩大视觉改动范围。

## 测试

- 在现有数据同步前端契约测试中增加 CSS 断言：页面定制选择器必须声明不透明背景，且不得再次使用 `transparent`。
- 先运行新增断言并确认它因现状失败，再修改生产样式使其通过。
- 运行完整的数据同步前端测试，确认 Tab、数据面板和既有交互契约不受影响。

## 范围外事项

- 不调整数据同步页头、状态卡片或内容布局。
- 不更改 Tab 切换逻辑和键盘可访问性。
- 不修改其他工作台的滚动或吸顶样式。
