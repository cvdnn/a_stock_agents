# astock-action-execution — 实战交易反应动作与精确保本决策中枢

## 定位与核心价值

**astock-action-execution** 是 A股量化投研系统的**执行反应中枢 (EMS 2.0)**。它将静态的技术分析与评分转化为**盘中毫秒级可执行动作**，杜绝散户因犹豫、幻想、四舍五入摩擦成本计算不准导致的隐性亏损。

底层由 `core/strategy/execution_action_engine.py` 驱动，支持微观订单生成、自然语言意图提取、保本价进位与三场景即时预案。

## 核心法则一：最低保本卖出价向上进位法则（铁律）

在 A股实战中，卖出时必须扣除各项税费：
1. **卖出印花税**：`0.05%` (双向买入免，仅卖出征收)
2. **券商佣金**：万分之 2.5 (`0.025%`)，**强制单笔最低 5 元起收**
3. **过户费**：十万分之 1 (`0.001%`，双向收取)

### 进位公式
为彻底杜绝因普通“四舍五入”导致的隐性亏损，系统执行**强制向上精确进位至分位（`math.ceil(price * 100) / 100`）**：

```python
# 最低保本卖出价计算逻辑
# 设买入成本买价为 cost, 持仓股数为 shares:
buy_amount = cost * shares
buy_comm = max(5.0, buy_amount * 0.00025)
buy_trans = buy_amount * 0.00001
total_buy_cost = buy_amount + buy_comm + buy_trans

# 求解满足: 卖出净回款 >= total_buy_cost 的最低单价 min_sell_price
# 卖出税费 rate = 0.0005 (印花税) + 0.00025 (佣金) + 0.00001 (过户费) = 0.00076 (0.076%)
# 佣金同样遵循最低 5 元规则
# 最终结果强制 math.ceil:
min_sell_price = math.ceil(raw_price * 100.0) / 100.0
```

> **实战示例**：以 10.00 元买入 1000 股（总金额 10,000 元）：
> - 普通四舍五入算出的保本价为 10.01 元，但由于最低佣金 5 元 + 印花税 5 元，实际卖出若为 10.01 元仍会净亏损 1.4 元。
> - 本引擎强制进位计算得出最低保本卖出价为 **`10.02 元`**，保本即盈利！

## 核心法则二：三级风控阶梯止损线

针对持仓浮亏，系统严密设定动态三级防线：

| 止损级别 | 阈值 | 触发条件 | 实战执行指令 |
| :--- | :---: | :--- | :--- |
| **T0 警戒线** | **-3.0%** | 跌破日内均线或关键支撑 | **立即触发盘中预警**。严禁任何补仓行为，密切盯盘。 |
| **T1 减仓线** | **-5.0%** | 破位放量下跌 | **坚决无条件减仓 50%**。锁定下行风险，保留半仓主动权。 |
| **T2 绝杀线** | **-8.0%** | 趋势彻底破位 | **无论任何消息/理由，无条件一键全清离场**。严禁扛单。 |

## 核心法则三：盘中三场景分级即时反应预案

系统自动识别个股盘中分时与量能形态，生成三场景分级动作单：

### 场景 1：开盘冲高回落（冲高 > +3% 随后遇阻）
- **触发情景**：早盘快速拉升但未封涨停，MACD 15分钟高位死叉或量能背离。
- **动作指令**：
  - 若持仓已有浮盈：挂**保本价上方或日内高点回落 1.5% 处**，挂限价卖出单锁定利润。
  - 若处于解套过程：达到保本价以上立即按阶梯出局（30% -> 30% -> 40%）。

### 场景 2：窄幅震荡阴跌（振幅 < 2%，量能萎缩）
- **触发情景**：全天缩量在昨日收盘价下方窄幅整理，均线粘合向下。
- **动作指令**：
  - 尾盘 14:30 确认无法站上 MA5/MA10 时，主动减仓降避隔夜低开风险。
  - 不做日内 T+0 频繁交易，避免摩擦税费损耗。

### 场景 3：盘中突发急跌跳水（5分钟跌幅 > 2.5%）
- **触发情景**：突发大单抛压、板块共振跳水或跌破 T0/T1 线。
- **动作指令**：
  - 第一时间核对是否触碰 T1（-5%）或 T2（-8%）。
  - 触碰 T1 立即自动执行市价/对手价半仓卖出；触碰 T2 绝杀清仓。
  - 严禁在急跌下坠飞刀过程中盲目抄底补仓。

## 五类下跌场景化诊断应对矩阵

| 场景类型 | 技术形态特征 | 核心原因诊断 | 战术应对决策 |
| :--- | :--- | :--- | :--- |
| **1. 假摔洗盘** | 缩量跌破短期均线，但守在 MA20 之上，筹码未松动 | 主力震仓吸筹 | **耐心持有**，在 MA20 企稳回升时可轻仓做 T |
| **2. 假突破真出货** | 盘中假突破新高后放巨量长上影阴线跳水 | 诱多派发筹码 | **果断止盈/离场**，破突破位坚决清仓 |
| **3. 均线反抽受阻** | 破位后弱势反抽至 MA5/MA10 无力突破 | 弱势下跌中继 | **逢反抽减仓**，绝不抱有再创新高幻想 |
| **4. 筹码松动破位** | 获利盘比例剧降，高位筹码峰快速下移 | 主力彻底撤离 | **无条件止损**，执行 T1/T2 纪律 |
| **5. 情绪恐慌错杀** | 行业无利空、个股基本面优良，随大盘暴跌 | 市场系统性风险 | **观察大盘止跌信号**，未破核心支撑可待修复 |

## 快速使用命令 (CLI)

```bash
# 1. 自动读取 output/pools/positions.csv 中持仓，生成全量持仓的保本价与反应预案
astock action plan

# 2. 评估指定单只持仓标的（成本 15.00，持仓 1000 股）
astock action plan --code 600519 --cost 1500.0 --shares 100

# 3. 输出 JSON 格式供前端面板或外部程序接入
astock action plan --json
```
