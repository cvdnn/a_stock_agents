# A股预测模型可靠性验证

## 定位

在决定是否把任何外部预测模型（Kronos、TimesFM、Chronos、自训时序模型等）作为信号接入 A股分析平台之前，
**先在真实 A股数据上做严格的样本外检验**。开箱即用的跨域基础模型极少能跑赢朴素基线——必须实测，不能信论文/README/demo。

## 决策铁律

1. 外部预测模型默认**不集成**，除非在 A股样本外检验中**同时**满足：
   - 方向命中率显著 >50%（超出约一个标准误），且
   - MAPE 优于"昨收不变"朴素基准（比值 <1）。
2. 计入集成成本：torch + 权重下载、是否需 GPU、CPU 推理速度。收益 ≈ 0 时任何依赖都是负资产。
3. 跨域（加密/美股为主）训练的模型，对 A股的有效路径是**领域微调**（如 Kronos 的 Qlib 微调管线）——那是独立工程，不是给平台打补丁。

## 复用方法：滚动样本外检验

### 数据
腾讯前复权日K线（`a-stocks` 的 `data_bridge.tencent_kline`），每只拉约 800+ 根（约3年）。
选 4-6 只代表标的（不同板块/波动特征）+ 1 只指数，避免单一样本偏差。

### 设计（无未来函数）
- `lookback=400`（适配 Kronos 512 上下文）→ 预测未来 **20 个真实交易日**，与**已存在于历史中的真实走势**比对。
- 滚动 `stride=40` → 每只约10窗口；6只 × 10 ≈ **n=60 样本/水平**。
- 关键：用完整历史拉数据到"今天"，预测截止点 T 之后 20 日的真实值**已存在**，可对照。别预测"今天之后"的未来（无真值可比）。

### 基线（缺一不可）
| 指标 | 基线 | 判据 |
|:-----|:-----|:-----|
| 方向命中率 | 随机 50%（n=60 时标准误 ≈ ±6.5%） | 命中率须超出一标准误才算有方向优势 |
| 方向命中率 | 动量基线 = 预测方向取"昨收方向" | 看是否跑赢简单动量 |
| 价格精度 | MAPE vs **昨收不变**朴素基准 | 比值 <1 才算跑赢朴素 |

### 稳定化
- `sample_count=3` 平均多条采样路径；固定 `torch.manual_seed`。
- 结果写 JSON 增量保存（长时运行防丢进度）。
- 无 GPU 时优先跑最小模型、用 `predict_batch` 批量，别逐窗口串行。

## 验证清单
- [ ] 数据拉到"今天"，保证预测窗口的真实值已存在
- [ ] 同时报方向命中率(1/5/10/20日) 和 MAPE/朴素基准比值
- [ ] 给出标准误（n 决定 ±%），避免把小样本当结论
- [ ] 结论落为"集成 / 不集成 / 需微调"，不模棱两可
