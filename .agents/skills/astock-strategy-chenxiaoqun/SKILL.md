# 陈小群游资超短战法决策体系 (Chen Xiaoqun Trading Strategy)

## 适用范围与核心定位

本 Skill 将 90 后新生代顶级游资**陈小群**（招牌席位：**中国银河证券大连金马路 / 大连黄河路 / 中信证券大连分公司**）在 A 股实战中打造浙江建投、中通客车、西安饮食、新华制药、巨轮智能、剑桥科技等超级大牛股的核心操盘哲学与模式，转化为系统化、高胜率的量化场景决策体系。

核心聚焦回答 4 类实战问题：
1. **灵魂龙头识别**：当前题材是否具备超级主线属性？标的是否为全市场唯一或辨识度最高的情绪总龙头？
2. **四大经典战法形态匹配**：
   - **战法一：总龙头分歧深水核按钮低吸（大长腿 / 地天板）**
   - **战法二：爆量烂板次日竞价超预期弱转强（秒板抢筹）**
   - **战法三：主升浪中军大格局换手板与做T锁仓**
   - **战法四：龙头首阴企稳反包与二波起爆**
3. **龙虎榜席位合力研判**：大连金马路等游资主力进出、锁仓格局、游资协同与对手盘分析。
4. **铁律风控与场景化执行**：强制贯彻 A-Stock 实战交易三原则（保本价向上进位 `ceil`、-3%/-5%/-8% 三级止损、冲高/震荡/急跌三场景动作单）。

## 核心哲学：“非龙头不买，分歧日低吸，一致日锁仓”

1. **唯一性与辨识度**：不做杂毛，不做跟风。若非板块总龙头或超级中军，任何买点都不成立。
2. **分歧产生美，一致容易亡**：高位一字加速缩量容易炸板被核，充分换手、筹码反复沉淀的换手板才能走得更远。
3. **弱转强是超预期的灵魂**：昨日烂板或大跌分歧，次日竞价超预期高开抢筹，展现主力强势态度。
4. **有风控才有资格谈格局**：逻辑破位、主线退潮时坚决杀伐果断，拒绝侥幸。

## 实战交易三原则（强制输出契约）

无论命中何种战法，输出分析报告时**必须强制包含以下三项要素**：

### 1. 精确最低保本卖出价 (Ceil Rounding)
严格按照印花税（0.05%）、佣金（万2.5且最低5元起收）、过户费（十万分之一双向）核算成本，并**强制向上进位至分位（`math.ceil(p * 100) / 100`）**，拒绝任何四舍五入。
$$\text{最低保本价} = \text{ceil}\left( \frac{\text{买入全成本} + \text{卖出佣金}(\ge 5\text{元}) + \text{过户费}}{\text{持仓股数} \times (1 - 0.0005)} \right)$$

### 2. 三级风控止损阶梯
- **T0 警戒线（$-3\%$）**：日内跌破此线，停止买入，进入防御观察；
- **T1 减仓线（$-5\%$）**：跌破 MA5/MA10 或亏损达 $5\%$，无条件减仓 $50\%$，锁定风险；
- **T2 绝杀线（$-8\%$）**：破位跌破 $8\%$，假突破或弱转强被证伪，坚决清仓，绝不锁仓意淫。

### 3. 三场景即时动作单
- **场景 A：开盘冲高**：冲高幅度、分时量能配合情况、是否封死涨停，若无法封板则执行冲高兑现减仓；
- **场景 B：盘中窄幅震荡**：围绕分时均线横盘洗盘的承接观察、做 T 差价区间；
- **场景 C：盘中跳水急跌**：若破分时均线伴随放量，触及 T0/T1 警戒位时的果断减仓或止损保护。
