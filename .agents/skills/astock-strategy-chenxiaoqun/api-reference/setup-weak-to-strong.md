# 战法二：爆量烂板次日竞价超预期弱转强模型 (Weak-to-Strong)

“弱转强是超预期的灵魂”。陈小群体系极其重视集合竞价的资金态度，尤其是前一日经历高换手分歧、多次炸板或烂板的龙头股，次日竞价的超预期表现是主升加速的最强烈信号。

---

## 1. 战法机理与底层逻辑

- **前日形态（弱）**：
  前一天股票多次开板、烂板、封单脆弱，或者收出带长上影线的大换手阳线（换手率 $>20\%$）。按照常规博弈预期，次日持股者应竞价恐慌抢跑，理应大幅低开（$-2\% \sim -5\%$）。
- **次日表现（超预期转强）**：
  集合竞价期间，主力资金不给场外低吸机会，直接动用数千万元买单挂涨停价抢筹，开盘价不仅不低开，反而**平开或大幅高开 $+2\% \sim +6\%$**，开盘后几分钟内资金蜂拥而入，迅速放量封死涨停板。

---

## 2. 集合竞价确认 Checklist (9:15 - 9:25)

1. **9:20 - 9:25 不可撤单阶段**：
   - 竞价价格稳步上行或保持在 $+2\% \sim +6\%$，无下砸撤单迹象；
   - 竞价匹配成交金额显著放大：**9:25 集合竞价成交额占昨日全天成交额的 $5\% \sim 10\%$ 以上**；
2. **量比与未匹配量**：
   - 开盘集合竞价量比 $\ge 15$；
   - 竞价最后一笔（9:25:00）买盘未匹配量显著大于卖盘未匹配量。
3. **主线梯队呼应**：
   - 板块内有一字板首板或前排助攻快速封板，印证板块情绪高涨。

---

## 3. 实战交易执行

- **买点 A（竞价跟随）**：
  9:24:30 确定超预期高开且成交量达标，直接挂高于现价1-2个点甚至涨停价买入 $30\% \sim 50\%$ 仓位；
- **买点 B（开盘秒板确认）**：
  9:30 开盘后股价不破分时均线、成交量急剧放大、红柱推升直奔涨停时，在回封或打板瞬间扫单买入。

---

## 4. 假弱转强识别与失效退出 (Invalidation)

游资圈常见“假弱转强诱多”陷阱，出现以下特征必须立即撤单或止损：

1. **竞价量能严重匮乏（缩量高开）**：
   - 高开 $+3\%$ 但竞价成交额极小（不足昨日成交额的 $1.5\%$），开盘后 9:30 瞬间出现万手大砸单；
2. **开盘3分钟内跌破分时均线**：
   - 开盘放量冲高后迅速回落，跌破集合竞价开盘价并跌穿分时均线，反抽无力；
3. **板块后排无助攻**：
   - 板块指数翻绿，其他同概念股纷纷低开下挫，该股成为孤勇者。

> ⚠️ **应急风控**：一旦开盘买入后被砸成天地板或跌破分时均线，立即启动三级风控：
> - 跌破买入价 $-3\%$ 停止一切加仓；
> - 跌破 $-5\%$ 触发 T1 减仓一半；
> - 尾盘若无法回封且亏损达 $-8\%$，次日早盘集合竞价坚决清仓。
