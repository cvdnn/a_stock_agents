## 2. 席位操盘风格与“指纹”特征

1. **“点火扫单”绝不拖泥带水**：
   盘中一旦识别出分歧转一致拐点，大单快速扫掉上方所有压单，极短时间内拉升 $5\% \sim 8\%$ 直封涨停板。
2. **“大格局锁仓”拒绝砸盘一日游**：
   不同于“量化基金”或“温州帮”的次日竞价恶意抢跑砸盘，陈小群在真正的总龙头中表现出极佳的锁仓胸怀，次日甚至继续补单助攻封板，给足接力资金利润空间。
3. **“做T换手”消化浮筹**：
   在上亿资金重仓的中军标的中，经常出现在买入前五和卖出前五同时上榜（如买入1.2亿，卖出8000万），通过高抛低吸降低整体持仓成本。
4. **“断臂求生”极具纪律性**：
   若判断失误或板块彻底退潮，陈小群席位次日集合竞价或早盘会坚决市价单斩仓出局，从不抱有死扛解套的幻想。

## 3. 龙虎榜合力与对手盘研判

- **顶级游资合力榜 (Super Bullish 🟢)**：
  - 买方席位：大连金马路 + 呼家楼（中信建投北京东城分公司等） + 章盟主（国泰君安上海江苏路） + 方新侠（中信西安朱雀大街）等顶级游资形成合力共振；
  - 卖方席位：主要是获利盘普通散户营业部或机构分歧卖出；
  - 结论：多头动能强劲，溢价率极高。
- **散户接盘派发榜 (Danger 🔴)**：
  - 买方席位：清一色“拉萨天团”（东方财富拉萨团结路、东环路等散户大本营）；
  - 卖方席位：大连金马路单向净卖出上亿元；
  - 结论：主力资金已完成出货派发，次日大概率直接大幅低开或跌停，严禁接盘！
