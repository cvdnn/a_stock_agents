# 仓位阶梯与资金管理法则 (Position Discipline)

陈小群的成功不仅依靠选股眼光，更得益于其极其严谨的资金管理策略——“在确定性低时轻仓试错，在总龙主升时敢于重仓聚焦，在风险退潮时空仓保命”。

---

## 1. 仓位等级划分 (Position Tiers)

```
       ┌────────────────────────┐
       │   P3: 进攻重仓 (50-80%) │ ◄── 阶段2：总龙主升 / 弱转强连续加速
       ├────────────────────────┤
       │   P2: 标准中仓 (30-50%) │ ◄── 阶段3：高位中军做T / 龙头首阴二波
       ├────────────────────────┤
       │   P1: 试错轻仓 (15-30%) │ ◄── 阶段1：新题材混沌启动 / 深水低吸试探
       ├────────────────────────┤
       │   P0: 绝对空仓 (0%)     │ ◄── 阶段4：主线退潮 / 高位股大面积A杀
       └────────────────────────┘
```

1. **P1 试错仓位 (15% ~ 30%)**：
   - 适用：混沌启动期、首阴第一脚回踩、深水跌停撬板试探；
   - 原则：哪怕完全看错止损出局，对整体总账户净值的回撤影响严格控制在 $1.5\%$ 以内。
2. **P2 标准仓位 (30% ~ 50%)**：
   - 适用：分歧转一致次日得到盘面确认、主线中军大票波段做T；
   - 原则：已有盈利垫保护，可以提升风险敞口。
3. **P3 重仓格局 (50% ~ 80%)**：
   - 适用：全市场唯一超级总龙头处于情绪主升期，连板态势明确，板块梯队极强；
   - 原则：不可分散在 3 只以上标的，集中火力打最有辨识度的灵魂龙头。
4. **P0 强制空仓 (0%)**：
   - 适用：连板高度骤降、跌停家数连续放大、前期老龙头连续跌停被按死；
   - 原则：关掉软件，绝对管住手，不参与任何诱多反抽。

---

## 2. 账户回撤控制与强行降频保护

1. **单日最大亏损红线**：
   若单日总资产回撤达到 **$-3\%$**，当日立即锁死交易账户，不再开任何新仓！
2. **连续两次止损强制冷静期**：
   若连续两笔超短交易均触及 T1 或 T2 止损线，表明当前市场节奏与模式不匹配，**强制休市 2 个交易日**，只做复盘，不进行任何实盘买卖。
3. **单票集中度上限**：
   除非总资金处于极小规模（50万以下），单只个股持仓市值原则上不得超过总资产的 $50\%$，防范突发黑天鹅或无量跌停无法卖出。
