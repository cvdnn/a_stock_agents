# 战法一：总龙头分歧深水核按钮低吸模型 (Deep Water Dip)

陈小群最震撼业内的手笔是在**总龙头遭遇恐慌踩踏砸入深水甚至跌停时，大单逆向点火承接，拉出地天板或十几个点的大长腿**（经典战役：浙江建投深水撬板地天板、中通客车水下承接拉板）。

---

## 1. 战法逻辑与适用标的

- **核心前提**：
  必须是全市场**辨识度第一**、**成交额前五**的主线总龙头。
  **绝对禁止**将此战法用于跟风股、中位股或杂毛（中位股核按钮会直接A杀封死跌停，只有总龙头才具备情绪扭转的号召力）。
- **心理学机制**：
  早盘恐慌盘集中踩踏，获利盘不计成本止盈甚至恐慌割肉，导致股价非理性下杀。主力资金在深水接住筹码后，只需少量买单点火即可引发全市场合力追随，日内完成十几个点的筹码交换。

---

## 2. 触发条件 (Trigger Checklist)

符合以下**全部五项条件**方可触发买入信号：

1. **总龙地位**：前一个交易日为连板龙头或人气冠军，今日没有被新题材总龙头完全卡位。
2. **下杀幅度**：早盘快速下砸，日内跌幅达到 **$-5\%$ 至 $-10\%$（跌停板附近）**。
3. **分时量能堆积（爆量承接）**：
   - 股价到达深水区后，成交量柱显著放大（超过开盘前10分钟均量的2倍以上）；
   - 盘口出现单笔万手级别或数千手级别的主动性大买单连续吃单，分时线上出现密集红柱。
4. **分时结构反转（W底或V型反弹）**：
   - 深水区两次触底不创新低，或者快速V型拉起；
   - 股价向上突破并站稳分时黄线（分时均价线）。
5. **板块梯队未团灭**：
   - 同板块内仍有首板助攻或前排中军保持红盘震荡，没有出现整个板块大面积一字跌停潮。

---

## 3. 入场点位与分批建仓

- **第一笔（底仓 15%）**：跌至 $-7\% \sim -9\%$（或跌停板被撬开瞬间）并出现万手承接单时试探入场；
- **第二笔（确认仓 15%）**：股价快速拉升放量突破分时均价线并回踩不破时加仓；
- **总持仓上限**：单票不超过总资金的 30%（分歧日依然保留风控冗余）。

---

## 4. 失效条件与止损铁律 (Invalidation)

出现下列任一情况，视为战法失效，执行退出：

1. **撬板失败封死跌停**：大单撬开跌停板后，买盘后续乏力，再度被大单封死跌停板且封单持续增加 $\to$ 次日竞价直接按跌停板计提止损；
2. **反弹无力再度破底**：反抽至分时均线附近即遇大卖单砸回，并跌破早盘深水最低点 $\to$ 触发日内 T0/T1 止损，放弃加仓并找反抽高点减半；
3. **板块整体崩塌**：板块内其他中军及高位股相继炸板跳水、多只个股封死跌停 $\to$ 情绪退潮不可逆，立即放弃幻想。
