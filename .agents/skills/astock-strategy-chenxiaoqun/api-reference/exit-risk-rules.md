# 风控与坚决止损纪律 (Exit & Risk Rules)

“会买的是徒弟，会卖的是师父，敢止损的是祖师爷”。超短交易最大的破产风险在于：将一笔短线试错单在亏损后因为侥幸心理做成了死扛中长线。

本体系严格遵循 **A-Stock 实战交易三原则**，任何买入操作必须强制绑定最低保本价与三级止损阶梯。

---

## 1. 精确最低保本卖出价核算公式

必须计算买入及卖出全流程税费，并强制向上进位至分位（`math.ceil`），拒绝任何四舍五入！

### 费用明细标准
1. **证券交易印花税**：卖出时单向收取 $0.05\%$（万分之五）；
2. **券商交易佣金**：买卖双向收取，标准为万分之 $2.5$（$0.025\%$），**单笔佣金不足 5 元按 5 元足额收取**；
3. **证券交易过户费**：买卖双向收取，按成交金额的 $0.001\%$（十万分之一）核算。

### 精算公式
设买入均价为 $P_{\text{buy}}$，股数为 $N$（股），买入总成本 $C_{\text{buy}} = P_{\text{buy}} \times N + \max(5, P_{\text{buy}} \times N \times 0.00025) + P_{\text{buy}} \times N \times 0.00001$。

则最低保本卖出价 $P_{\text{breakeven}}$ 为：
$$P_{\text{breakeven}} = \frac{\lceil \left( \frac{C_{\text{buy}} + \max(5, P_{\text{est\_sell}} \times N \times 0.00025) + P_{\text{buy}} \times N \times 0.00001}{N \times (1 - 0.0005)} \right) \times 100 \rceil}{100}$$

## 2. 三级风控止损阶梯 (Stop-Loss Ladder)

| 止损层级 | 触发阈值 | 对应市场含义 | 强制执行动作 |
| :--- | :--- | :--- | :--- |
| **T0 警戒线** | **$-3.0\%$** | 日内分时回落跌破买点支撑，多头动能减弱 | **停止买入并挂单警戒**<br>禁止日内继续加仓补仓，密切盯盘分时均线。 |
| **T1 减仓线** | **$-5.0\%$** | 跌破 MA5 生命线或竞价弱转强假突破成立 | **无条件减仓 50%**<br>卖出一半持仓，强制压缩风险敞口，保留本金。 |
| **T2 绝杀线** | **$-8.0\%$** | 逻辑彻底证伪，遭遇恶性核按钮或跌停A杀 | **无条件清仓出局 (100%)**<br>直接挂市价单坚决离场，绝不意淫回本，绝不死扛！ |

## 3. 三场景即时动作单 (Three-Scenario Action Plan)

针对次日盘面可能出现的极端分化，在开盘前必须制定好三场景动作单：

### 场景 A：开盘冲高
- **触发条件**：9:30 - 10:00 快速拉升涨幅 $>+5\%$，或直接封板。
- **应对动作**：
  - 若伴随巨量且封单坚决，锁仓格局；
  - 若冲高至 $+6\% \sim +8\%$ 出现大单滞涨、量能衰竭、多次冲板不封，**立即逢高止盈减半或清仓**。

### 场景 B：盘中窄幅震荡
- **触发条件**：全天围绕昨日收盘价或分时均线在 $[-2\%, +3\%]$ 之间横盘波动。
- **应对动作**：
  - 若在分时均线上方且大盘无系统性风险，保持底仓观望；
  - 若持有中军大票，可在回踩均线低点时加仓、冲高时减仓做日内 T+0。

### 场景 C：盘中跳水急跌
- **触发条件**：盘中出现万手连续大抛单，跌破早盘低点并向下跳水。
- **应对动作**：
  - 触及 **$-3\%$（T0线）** 时取消所有买单；
  - 触及 **$-5\%$（T1线）** 时立即市价卖出一半；
  - 触及 **$-8\%$（T2线）** 或出现跌停迹象时，毫不犹豫市价全部清仓！
