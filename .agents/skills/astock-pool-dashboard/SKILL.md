## 模块十一：cron监控部署体系（2026-07-21新增）

### 11.1 三脚本架构

对于单只重要持仓（如000400许继电气），部署三个互补脚本覆盖全天：

| 脚本 | 执行时间 | 用途 | 数据来源 |
|------|:--------:|------|----------|
| **竞价分析** | 09:25-09:30 | 评估主力竞价意图（抢筹/试盘/压盘/出货） | 腾讯行情 |
| **午盘分析** | 11:30-12:00 | 半日量价汇总+资金流向+板块位置+午后预判 | 腾讯+tick+资金流+板块排行 |
| **全天监控** | 每5分钟 | 止损/止盈/异动检测+组合盈亏+散户思维提示 | 腾讯行情 |

### 11.2 竞价分析脚本模式

评估开盘15分钟的主力行为，输出开盘意图判断和操作建议：
- 采集竞价量价（09:20-09:25）
- 对比昨收、前日竞价量/价
- 主力意图分类：抢筹/试盘做多/中性观望/压盘洗盘/恐慌出货
- Windows Toast 推送

### 11.3 午盘分析脚本模式

在11:30收盘后立即分析早盘：
- 半日K线数据（开高低收+量）
- 买/卖盘比
- 主力资金净占比（近3日）
- 所属板块排名扫描
- 走势分类：强势拉升/温和走强/偏强震荡/冲高回落/弱势整理/明显走弱
- 午后预判及操作建议

### 11.4 全天持仓监控脚本模式 (portfolio_monitor.py)

全组合风控，每5分钟检测，包含6层触发条件：

```
批量腾讯行情 → 遍历所有持仓:
  1. 止损触发 → 🔴红色推窗
  2. 止盈触发 → 🟢绿色推窗
  3. 接近止损<3% → 🟠橙色预警
  4. 单日跌>3% → 📉异动提醒
  5. 组合盈亏汇总
  6. 每日首次 → 散户思维提示弹窗
  7. 可用资金提示
```

### 11.5 定时监控部署速查

使用系统 crontab 或本地守护进程定时调度：
```bash
# 竞价分析（09:25-09:30间执行）
# 30 9 * * 1-5 cd /path/to/a_stock_agents && ./bin/astock evaluate 000400 --json

# 午盘分析（11:30执行）
# 0 12 * * 1-5 cd /path/to/a_stock_agents && ./bin/astock evaluate 000400 --json

# 全天持仓风控监控（盘中每5分钟）
# */5 9-11,13-14 * * 1-5 cd /path/to/a_stock_agents && ./bin/astock pool audit --json
```

### 11.6 定时任务路径规范

- 始终在项目根目录下执行 `./bin/astock` 或 `python core/cli.py`
- 监控产生的数据与状态持久化保存于 `output/cache/` 或 `output/positions/`，遵循数据隔离标准
- 脚本内所有子进程调用统一使用 `sys.executable`（保证虚拟环境一致性）
- 脚本内所有 `subprocess.run` 调用 `sys.executable` 而非硬编码 `python3`（兼容cron环境）
- 所有文件路径使用绝对 `Path` 或 `Path.home()` 构建，不依赖 `__file__` 推导

### 11.7 Python 3.9 兼容陷阱 ⚠️

系统 Python 3.9 不支持 `dict[str, Any] | None` 等联合类型语法（Python 3.10+）。在 WSL 系统 `python3` 下运行 cron 脚本时会 SyntaxError：

```python
# ❌ 不支持（Python 3.10+）
def fn() -> dict[str, Any] | None:
  ...

# ✅ 兼容写法（Python 3.9）
def fn():
  ...
```

**规则**：所有部署到 cron 的 no-agent 脚本必须去掉联合类型注解。脚本顶部不留 `from typing import Any` 等不再使用的 import。

## 模块十二：散户行为矫正与可用资金管理（2026-07-21新增）

### 12.1 反散户思维提示器

全组合监控脚本内置8条警示语的随机轮换库，每日首次运行自动推窗：

```
🔔 不要因为涨了就去追，不要因为跌了就恐慌割肉
🔔 频繁看盘 = 频繁交手续费
🔔 亏损时死扛、盈利时急着卖 — 这都是散户天性
🔔 市场上90%的消息你读到时已经反映在价格里了
🔔 可用资金不是用来'补仓摊平'的
🔔 记住你是你投资组合的CEO
🔔 如果今天你没操作但睡得很好，这是成功的一天
🔔 不要因为某只股涨了就后悔 — 你只错过了你没冒的风险
```

### 12.2 可用资金提示

监控脚本在每次输出中都显示可用资金（硬编码常量 `AVAILABLE_CASH`），交易时段首次触发时单独推窗一次。核心原则：可用资金用于确定性机会加仓，不是补仓摊平工具。

### 12.3 应用场景

当用户询问"xxx能不能补仓"时，判断路径：
1. 技术面回踩确认的加仓机会？ → 分析后决定
2. 浮亏后想摊平成本？ → 禁止（触发反散户提示）
