### 核心问题

1. combo_scorer在L1模式(70分制)下，对茅台这种万亿龙头从未给过A级信号 → 评分阈值在70分制下校准不当

3. 仅5日窗口判定方向 → 排除先跌后涨(可能已止损)的场景

## 四、paper_trading 回测引擎审查

### 已有能力

- 3种策略: buy_and_hold / sma_cross / rsi_revert
- A股成本: 佣金max(5, amount*0.03%) + 过户费(沪市0.001%) + 印花税(卖出0.1%)
- A股约束: 100股整数倍 + 涨跌停过滤 + T+1(position_lots.acquired_date)
- 回测指标: 总收益率 + 最大回撤 + win/loss count + equity_curve(后60条)

### 已知问题

| 问题 | 详情 |
|------|------|
| 印花税过期 | engine.py calc_tax用0.1%，2023.8.28起减半至0.05% |
| 佣金偏高 | 万3，行业主流万2.5 |
| 无夏普比率 | 无年化波动率计算 |
| 无卡尔玛/索提诺 | 缺失核心风险调整收益指标 |
| 无年化收益率 | 无250交易日换算 |
| 无超额收益 | 无buy_hold基准对比 |
| 无换手率 | 无交易频率统计 |
| equity_curve截断 | 仅保留后60条，无法看完整曲线 |
| 单股回测 | 不支持组合 |
| 策略硬编码 | 无策略接口抽象，无法接入combo_scorer |
| 无滑点 | 高频策略回测偏高 |

### 技术选型结论

推荐方案A: 基于paper_trading引擎扩展(~400行新增)

理由:
- 已有正确的A股约束建模(T+1/涨跌停/100股)
- 零外部依赖与a-stocks体系一致
- 工作量最小，风险最低

实现路径:
1. Phase 1: 策略接口抽象(~80行) — BacktestStrategy基类 + 各策略子类
2. Phase 2: backtest_metrics.py(~150行) — 夏普/卡尔玛/索提诺/年化/换手率
3. Phase 3: 成本模型校正(~30行) — 印花税0.05% + 佣金可配置默认万2.5 + 滑点0.1%
4. Phase 4: 基准对照(~40行) — 同时跑buy_hold + 超额收益输出
5. Phase 5: 完整equity_curve(~20行) — 去截断

## 五、新增策略模块方案

### 模块D: 布林带均值回归

买入: 收盘<BOLL下轨 + 量比<0.8 + RSI<30 + 距MA60>-15% + 大盘≥45
卖出: 收盘>BOLL中轨减半 / >BOLL上轨清仓 / RSI>70清仓
止损: 入场价-3% 或 BOLL下轨-1ATR
仓位: 单股10%，组合≤20%

### 模块E: 动量排名选股

Step1: 去ST/创业板/科创板/北交所
Step2: 60日涨幅排名TOP50
Step3: 20日动量分 = (收盘/MA20 - 1) * 100
Step4: combo_scorer ≥49分
Step5: 距MA20<3%优先
轮动: 每周一次调仓
仓位: 5-8只, 单股15%

### 模块J: 组合优化器

- 60日收益相关系数矩阵
- 风险预算: 单股≤15%, 行业≤30%
- 仓位上限受大盘健康度约束
- 纯标准库实现(无numpy)

### 模块K: 市场路由器

| 大盘分数 | 策略权重 |
|---------|---------|
| ≥85 强牛市 | 动量50% + 趋势30% + 涨停20% |
| ≥65 结构性 | 趋势50% + 多因子30% + MACD20% |
| ≥45 弱震荡 | 布林40% + 网格30% + MACD30% |
| <45 系统下跌 | 空仓/最低 + 仅MACD修复轻仓 |

## 六、评估模型v2设计（改进strategy_evaluator四维模型）

### 现有模型缺陷

1. **方向判定过粗**: 仅5日正负，无超额收益基准，无最大不利偏移
2. **评级校准形同虚设**: 宽松匹配宽到2个评级即得30分满分
3. **入场时机评分不完整**: 仅比较first vs far，中间档未参与
4. **样本充分性门槛低**: 5条即满分，统计意义极低

### v2六维模型 (100分)

| 维度 | 权重 | 改进点 |
|------|------|--------|
| 超额收益方向准确率 | 25分 | vs buy_hold基准算alpha方向，而非绝对收益正负 |
| 评级梯度单调性 | 20分 | 斯皮尔曼秩相关系数替代宽松匹配 |
| 入场时机区分度 | 15分 | 4档方差加权差异，非仅first vs far |
| 最大不利偏移(MAE)控制 | 15分 | A/B推荐后20日内最大回撤，衡量持有体验 |
| 多窗口一致性 | 15分 | 1d/5d/10d/20d四窗口方向一致性 |
| 样本充分性 | 10分 | ≥20个满分，≥10个6分，<5个0分 |

### 关键新增能力

- 超额收益基准 → 区分alpha和beta
- 最大不利偏移 → 衡量持有期间最痛体验
- 多窗口一致性 → 排除单窗口偶然性
- 秩相关系数 → 替代宽松匹配的校准评分
