# --tick 数据覆盖范围限制

## 问题说明

`fetch_realtime.py --tick CODE` 返回的数据**仅覆盖开盘后约前5分钟的成交明细**（实测约 09:25-09:30 区间）。不是完整的当日分笔成交记录。

## 影响

- 早盘分析（09:30-11:30）：--tick 数据不足以判断整个上午走势
- 午后分析（13:00-15:00）：--tick 同样仅覆盖开盘附近
- 全日分析：完全不适用

## 早盘分析的替代方案

| 需要 | 推荐命令 | 说明 |
|------|----------|------|
| 实时行情+涨跌幅 | `--multi-quote C1,C2` | 返回当前最新价、涨跌幅、昨收，可计算出早盘方向 |
| 盘中多次数据 | `execute_code` 中循环调 `--multi-quote` | 按时间戳分段合并 |
| 早盘高低点 | 盘中多次 `--multi-quote` 记录极值 | 无原生全天分时数据 |
| 昨日收盘参考 | `--quote CODE`（含昨收） | 与当前价对比得涨跌 |

## 根本原因

腾讯免费 tick API 仅返回最近 N 笔记录（有限缓冲区），开盘后早期数据随时间推移被新数据覆盖。不是技能脚本的问题，是数据源限制。
