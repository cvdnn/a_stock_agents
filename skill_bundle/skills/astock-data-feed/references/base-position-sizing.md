# 底仓评估方法论 — 科学确定最小保留仓位

## 适用场景

用户持有某只股票但评级为 D级（回避）/ C级（观望），需要确定"最小保留仓位"（底仓）时使用。底仓定义：在下跌趋势中保留的观察仓位，目的不是赚钱，而是保持敏感度 + 防止彻底踏空。

---

## 五种计算方法

### 方法一：ATR + 最大可承受亏损

```
每股风险 R = 当前价 - 止损价
最大底仓 = 可接受额外亏损 / R
```

| 风险偏好 | 可承受额外亏损 | 建议 |
|:--------:|:--------------:|:-----|
| 保守 | 总成本1-2% | 参考值 |
| 中性 | 总成本3% | 参考值 |
| 激进 | 总成本5%+ | ⚠ 对D级偏高 |

### 方法二：评级分位法

| 评级 | 建议仓位占比 |
|:----:|:-----------:|
| A级 | 60-100% |
| B级 | 30-60% |
| C级 | 15-30% |
| D级 | 0-15% |

```
底仓 = 总成本 × 评级对应比例上限 ÷ 当前价
```

### 方法三：凯利公式校验

```
f* = (p/b - q/a)

p = 反弹概率, q = 下跌概率
a = 反弹幅度%, b = 下跌幅度%

f* > 0  → 可以持有对应比例
f* < 0  → 凯利建议空仓（缩小底仓或零）
```

### 方法四：趋势结构法

```
强底仓（趋势逆转前）= 0
  等股价站稳MA20且均线走平 → 再建

弱底仓（保留观察）= 200-500股
  纯观察窗口，跌了不心疼，涨了有参与
```

### 方法五：机会成本法

```
底仓机会成本 = 底仓市值 × 年化理财收益率
月代价 = 机会成本 / 12

例：500股 × 42元 = 21,000元
  年机会成本 = 21,000 × 2% = 420元
  月代价 = 35元 → 每月35元保留一个观察窗口
```

## 综合决策树

```
                   当前持仓 N 股
                        │
                        ▼
          ┌──────────────────────────────┐
          │  中长期催化逻辑是否成立？    │
          │  (政策/产品/行业拐点)        │
          └──────┬───────────┬──────────┘
                 │ 否         │ 是
                 ▼            ▼
          ┌──────────┐  ┌─────────────────────┐
          │ 全部清仓 │  │ 保留最小底仓观察    │
          │ 底仓=0   │  │                     │
          │ 符合规则 │  │ 取方法一~四的       │
          │ 等趋势   │  │ 交叉最小值          │
          │ 逆转再买 │  │ 通常在100-500股     │
          └──────────┘  └─────────────────────┘
```

## 筹码分布辅助判断

从 `stock_cyq_em()` 获取的数据：

| 指标 | 含义 | 底仓决策影响 |
|:----|:------|:------------|
| 获利比例 < 5% | 95%+持仓者被套 | ⚠ 底仓应更小，上方抛压极大 |
| 当前价 < 90成本下沿 | 股价在筹码真空区 | 短期无密集抛压，可保留小底仓 |
| 90集中度 > 0.15 | 筹码高度发散 | 典型套牢结构，底仓不宜大 |
| 70成本下沿 | 核心密集区支撑/阻力 | 反弹到此区域需决定是否减仓 |

## 执行规范

### 输出格式

```
推荐方案：方案B — 底仓 X 股

核心理由：
  1. 评级X级 → 建议仓位占比X%
  2. 止损价X → 额外亏损可控
  3. 中长期催化逻辑（有/无）

当前操作：
  立即卖出 N 股（现价~X）
  保留 X 股作为底仓

底仓退出条件：
  □ 跌破止损价 → 无条件清仓
  □ Q3业绩验证低于预期 → 减至0
  □ 趋势逆转+站上MA20 → 可加回
```

### 多情景损益模拟

必须包含至少三种情景的损益模拟表：

| 未来走势 | 股价 | 底仓损益 | 已回收 | 总账户 |
|:--------:|:----:|:--------:|:------:|:------:|
| 继续下跌至止损 | X | -Y元 | Z元 | 总亏损 |
| 横盘震荡 | X | -Y元 | Z元 | 中性 |
| 催化反弹 | X | +Y元 | Z元 | 跟涨收益 |

### 底仓 = 0 时的退出再入场条件

当建议清仓时，必须给出明确的重新入场条件：
1. 技术面：日线底分型 + 站上MA5
2. 基本面：Q3单季净利润恢复至某水平
3. 政策面：十五五规划/产业政策发布后板块共振
