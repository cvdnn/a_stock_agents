# 7 角色多空对抗辩论机制与双向证据链规范

## 1. 角色分工与专业视角

为了打破单一模型单向分析的信息茧房，体检诊断内置 7 大专业量化分析师对抗推演机制：

| 分析师角色 | 核心职责与论证焦点 | 关键依据与数据锚 |
| :--- | :--- | :--- |
| **1. 基本面分析师** | 商业模式、护城河、财报排雷、业绩可持续性与估值水位 | ROE、营收与净利增速、PE/PB百分位、商誉与质押 |
| **2. 量价动能分析师** | 均线形态、K线组合、动量突破、成交量异动与技术背离 | MA5/10/20/60、MACD柱、BOLL通道、量比、换手率 |
| **3. 消息与政策分析师** | 国家产业政策支持度、行业催化剂、个股公告与突发舆情 | 产业政策红利、订单公告、定增重组、舆情偏向度 |
| **4. 游资博弈分析师** | 情绪周期身位、龙头战法属性、接力分歧与龙虎榜溢价 | 连板高度、封成比、炸板率、知名席位动向、弱转强 |
| **5. 筹码分布分析师** | 获利盘比例、平均建仓成本、筹码锁仓与套牢盘抛压位 | CYQ 获利盘比例、90% 集中度、筹码峰值价格 |
| **6. 首席风控精算官** | 最低保本卖出价、下行风险敞口、盈亏比测算与止损梯次 | 印花税+佣金精算、-3%/-5%/-8% 阶梯、凯利建议仓位 |
| **7. 投决会首席裁判** | 整合六方意见，计算综合多空评分，做出最终裁决与动作单 | 最终 S/A/B/C/D 评级、金字塔 BLUF 观点、即时执行动作单 |

## 2. 多空双向证据链铁律 (Bidirectional Evidence Chain)

任何多空结论严禁单一“看好”或“看空”口号，必须同时强制列出顶层证据：

### 2.1 Top 3 看多实证 (Top 3 Bullish Evidence)
- 实证 1：必须包含具体指标数值与在近 250 日中的分位（如：MACD 水下双金叉且 DIF 回踩 0 轴上扬）；
- 实证 2：必须指明资金面或筹码面硬证据（如：获利盘比例 86.4%，筹码集中度 7.2% 锁仓良好）；
- 实证 3：必须具备产业或题材驱动逻辑。

### 2.2 Top 3 风险证伪条件 (Top 3 Bearish & Invalidation Conditions)
- 证伪条件 1：关键均线跌破点（如：收盘价跌破 MA20 趋势破位）；
- 证伪条件 2：止损触碰底线（如：跌破保本价或触发 -5% 减仓线）；
- 证伪条件 3：微观博弈失效（如：次日早盘集合竞价低开超 -2% 且成交量萎缩）。
