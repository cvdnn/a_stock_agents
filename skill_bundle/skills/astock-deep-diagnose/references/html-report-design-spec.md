# 单文件自包含 HTML 投研交互报告设计与视觉规范

## 1. 核心设计原则

1. **自包含与免依赖 (Self-Contained & Zero External CDN)**：
   - 生成的 HTML 研报必须是单个完整的 `.html` 文件，所有样式（CSS）、图表脚本（SVG/Canvas）与数据内嵌；
   - 严禁引用不可达或需要联网的第三方外部 CDN，确保在离线完全隔离环境下完美渲染。
2. **专业买方视觉质感**：
   - 背景采用高质感亚光白/浅灰底色（`#F8FAFC`），字体选用 Inter/PingFang SC 现代无衬线字体；
   - 遵循国内 A股习惯：**红涨绿跌**（上涨 `#EF4444`，下跌 `#10B981`，中性 `#64748B`）；
   - 卡片微阴影与温润圆角，信息密度适中，杜绝大面积刺眼对比色。
3. **金字塔结论先行 (BLUF) 版面排布**：
   - **顶栏**：股票代码、名称、现价、涨跌幅、`evidence_meta` 溯源信封（交易日、数据源、K线根数、费率SSOT）；
   - **第一区【综合决策看板】**：100分大字打分环、S/A/B/C/D 评级勋章、大盘五维健康度三色灯、一句话投研核心结论；
   - **第二区【实战交易三原则执行单】**：
     - 最低保本卖出价（`math.ceil` 向上进位至分位，标注万2.5佣金最低5元+0.05%印花税+过户费）；
     - 三级止损价格表：T0 警戒线 (-3%)、T1 减半防守线 (-5%)、T2 绝杀线 (-8%)；
     - 三场景即时动作单（开盘冲高择机兑现 / 盘中窄幅震荡观望 / 盘中跳水急跌防御）；
   - **第三区【六维穿透与多空证据链】**：六维蛛网雷达图/柱状图，Top 3 看多实证 vs Top 3 风险证伪条件；
   - **第四区【解套决策与情景模拟】**（若提供持仓成本与股数）。
