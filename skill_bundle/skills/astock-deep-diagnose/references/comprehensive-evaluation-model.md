# A股个股全维穿透体检与100分量化评估模型

## 1. 模型架构与六维正交权重

本评估体系以买方机构投研标准构建，对标的进行 100 分制量化打分，由六大正交维度组成：

| 评估维度 | 权重占比 | 核心考察指标 | 数据来源与模型 |
| :--- | :---: | :--- | :--- |
| **宏观与大盘情绪共振** | **15%** | 大盘五维健康度（趋势/情绪/量能/结构/资金）、板块主力资金、主线板块身位 | `core.models.market_assessor` |
| **基本面与财务安全** | **25%** | ROE (扣非)、近3年营收/净利复合增速、商誉占比 (<15%)、质押率 (<20%)、经营净现金流/净利润比值 | `core.models.fundamental_filter` |
| **技术趋势与动能** | **20%** | 均线多头排列 (MA5>10>20>60)、MACD零轴与柱体动能、BOLL通道位置、RSI超买超卖、ATR真实波幅 | `core.indicators.technical_indicators` |
| **量价结构与筹码集中** | **20%** | 换手率分布、量比与量价背离、获利盘比例 (CYQ winner_rate)、90%筹码集中度、主力大单净量 | `core.data.cyq` |
| **游资博弈与微观结构** | **10%** | 连板高度、封单额与封成比、炸板率、龙虎榜知名游资席位溢价与多空换手充分度 | `core.strategy.chenxiaoqun` |
| **风控与头寸盈亏精算** | **10%** | `math.ceil` 向上进位保本卖出价、-3%/-5%/-8% 三级止损空间、受限凯利仓位建议 | `core.strategy.execution_action_engine` |

## 2. 评级档位与买方决策矩阵

根据最终综合得分，标的被严格划入 5 级评级体系：

| 得分区间 | 评级 | 买方投研结论 | 操作指引与仓位风控 |
| :---: | :---: | :--- | :--- |
| **85 ~ 100** | **S (极优)** | 强主线共振、业绩扎实、量价多头、筹码锁仓 | 重点配置标的，建议仓位 30%~50%，右侧加仓 |
| **70 ~ 84** | **A (优良)** | 趋势向上、基本面无雷、局部指标回踩支撑位 | 稳健型买点，建议底仓 20%~30%，分批低吸 |
| **55 ~ 69** | **B (中性)** | 震荡分化、缺乏强催化剂、个别指标存在瑕疵 | 观望或波段高抛低吸，单仓严控 15% 以下 |
| **40 ~ 54** | **C (偏弱)** | 趋势转弱、获利盘离场、短期破位风险增加 | 严禁左侧抄底，已有持仓触发 -3% 警惕减半 |
| **0 ~ 39** | **D (高危)** | 财务暴雷（商誉爆仓/高质押/ST）、均线破位空头 | 坚决回避，一票否决，已有持仓无条件绝杀止损 |

## 3. 五大财务硬排雷一票否决机制

无论技术形态多么优美，若触碰以下任一底线，**直接将总分一票扣减至 40 分以下，评级强行降为 D**：
1. **ST / *ST / 存在退市风险警示**；
2. **控股股东或实控人质押比例 $\ge 70\%$**（流动性危机与平仓踩踏风险）；
3. **商誉占净资产比例 $\ge 30\%$** 且近两年扣非净利连续下滑（商誉减值黑天鹅）；
4. **最近一年财务报告被出具保留意见、无法表示意见或否定意见**；
5. **近 3 年经营性现金流量净额累计为负且资产负债率 $\ge 75\%$**。
