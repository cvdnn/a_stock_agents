# 目标波动率与受限凯利头寸管理模型

## 1. 经典凯利公式在 A 股中的局限性与风险

经典凯利公式（Kelly Criterion）：
$$f^* = \frac{p \cdot b - q}{b} = \frac{p(b + 1) - 1}{b}$$
其中 $p$ 为胜率，$q = 1 - p$ 为负率，$b$ 为盈亏比。

在 A 股实战中，由于存在 T+1 制度、涨跌停板流动性受阻以及极端行情肥尾风险，直接套用全额凯利（Full Kelly）极易导致超高杠杆与大幅本金回撤。

---

## 2. 受限凯利（Fractional Kelly）与目标波动率约束

系统采用**受限半凯利（Half-Kelly）+ 目标波动率（Volatility Targeting）双重约束模型**：

### 2.1 受限半凯利
$$f_{safe} = \min(0.5 \times f^*, \; f_{cap})$$
- 基础仓位上限 $f_{cap} = 30\%$（单只股票最大配置比例不得超过总资金的 30%）；
- 若胜率 $p \le 50\%$ 且盈亏比 $b \le 1.5$，直接输出 $f_{safe} = 0\%$（放弃开仓）。

### 2.2 真实波幅 (ATR) 动态缩放
根据标的近 20 日真实波幅（ATR）与预设目标波动率对头寸进行反向缩放：
$$\text{头寸股数 } S = \left\lfloor \frac{\text{总资金 } \times f_{safe}}{\text{ATR}_{20} \times 2.0} \right\rfloor$$
将计算出的股数向下圆整至整百股（1 手 = 100 股），兼顾风险控制与 A 股申报规则。
