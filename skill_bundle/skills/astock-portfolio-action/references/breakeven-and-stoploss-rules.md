# 实战交易三原则与精确保本价、三级止损铁律

## 1. 最低保本卖出价精算规范 (`math.ceil`)

在 A 股交易中，卖出保本价必须全额覆盖买入及卖出双向的所有法定税费，并严格按照分位（2 位小数）**向上进位取整 (`math.ceil(p * 100) / 100`)**，坚决杜绝“四舍五入”导致的几分钱亏损。

### 1.1 规费单一来源 (SSOT)
- **印花税**：卖出时单向征收 **0.05%**（股票交易印花税）；
- **券商佣金**：买卖双向征收，标准费率 **万分之 2.5 (0.025%)**，单笔**最低 5 元起收**；
- **过户费**：买卖双向征收，标准费率 **0.001%**（沪深交易所统一规费）。

### 1.2 进位精算公式
设买入价格为 $P_{buy}$，股数为 $S$：
$$\text{买入成本总额 } C_{buy} = P_{buy} \times S + \max(5, P_{buy} \times S \times 0.00025) + P_{buy} \times S \times 0.00001$$
必须找到满足净回款 $R_{sell} \ge C_{buy}$ 的最小价格 $P_{sell}$，计算后执行进位：
$$P_{be} = \frac{\lceil P_{sell} \times 100 \rceil}{100.0}$$

## 2. 三级风控止损阶梯体系

持仓出现不利走势时，严禁情绪化死扛，严格触发三级防守阶梯：

| 风控级别 | 触发阈值 | 核心应对动作 | 仓位处置原则 |
| :---: | :---: | :--- | :--- |
| **T0 警戒线** | **$-3\%$** | 触发盘中告警，停止一切加仓操作，研判板块主线是否破位 | 准备减仓或利用反弹卖出，严禁左侧补仓 |
| **T1 减仓线** | **$-5\%$** | 坚决执行被动防守，防范个股破位深跌风险 | **无条件减仓 50%**，锁定剩余本金安全 |
| **T2 绝杀线** | **$-8\%$** | 判定该笔交易假设彻底被市场证伪 | **清仓出局，零容忍止损**，切断亏损扩散 |

## 3. 三场景即时实战动作单

无论何时输出持仓建议，必须清晰列出三种盘中情景下的触发价格与挂单指令：

1. **场景一：开盘冲高择机兑现**
   - 触发条件：早盘高开超 $+3\%$ 或 9:30~10:00 快速放量冲高触及阻力位；
   - 动作指令：分批减仓 30%~50%，兑现浮盈，保护本金。
2. **场景二：盘中窄幅震荡观望**
   - 触发条件：日内振幅处于 $[-1.5\%, +1.5\%]$，成交量温和萎缩；
   - 动作指令：卧倒不动，耐心等待方向选择，严禁频繁换手消耗手续费。
3. **场景三：盘中跳水急跌防御**
   - 触发条件：放量跌破分时均线且击穿 T0/T1 警戒线；
   - 动作指令：立即执行保本动作单或止损减仓，杜绝盘中幻想。
