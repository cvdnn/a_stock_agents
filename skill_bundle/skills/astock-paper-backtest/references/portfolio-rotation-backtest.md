# 多股组合轮动回测模型与基准对比规范

## 1. 组合轮动回测架构

在评估选股策略或多因子模型时，单股回测容易受到个股极端事件干扰，必须依托多股组合轮动引擎进行检验：

1. **组合初始化**：设定初始资金（默认 100 万元），设定基准指数（如沪深 300 `000300.SH` 或中证 500 `000905.SH`）；
2. **调仓周期**：支持日频、周频、双周频或信号驱动调仓；
3. **选股截面换仓**：
   - 依据评分模型选出 Top N 标的（如前 5~10 只）；
   - 按等权重、市值加权或受限半凯利权重分配资金；
   - 调仓日卖出掉出排名的标的，买入新入选标的；
4. **交易摩擦精算**：每笔调仓强制扣除印花税、双向佣金、过户费及 45bps 市场冲击滑点。

## 2. 机构核心评估指标输出

回测结束后，自动输出以下关键绩效指标（KPIs）：
- **累计年化收益率 (CAGR)**
- **基准超越收益 (Alpha)** 与市场敏感度 (Beta)
- **夏普比率 (Sharpe Ratio)** 与索提诺比率 (Sortino Ratio)
- **最大历史回撤 (Max Drawdown)** 与回撤持续期 (Drawdown Duration)
- **卡玛比率 (Calmar Ratio = 年化收益 / 最大回撤)**
- **月度胜率与盈亏比序列**
