# 高保真 A 股模拟交易撮合引擎设计与约束规范

## 1. 真实市场约束（拒绝虚假撮合）

模拟盘严禁任何脱离 A 股真实交易制度的“玩具级”撮合，必须完整实现以下硬约束：

| 市场制度约束 | 规则细节与处理逻辑 | 违规后果与防范 |
| :--- | :--- | :--- |
| **T+1 卖出锁定** | 当日买入股票记录为 `frozen_shares`，当日不可卖出，次交易日方可解锁 | 杜绝日内回转交易虚假高频套利 |
| **涨跌停板不可买卖** | 主板 10%、创业板/科创板 20%、ST 5%。涨停买一封死禁止买入，跌停卖一封死禁止卖出 | 杜绝在涨停价虚构买入龙头妖股 |
| **交易单位与碎股** | 买入申报数量必须为 100 股的整数倍（整手）；卖出允许一次性申报零碎股 | 对齐交易所委托规则 |
| **市场冲击与分位滑点** | 依据申报金额与盘口挂单量动态测算买卖滑点（默认 0.1%~0.25%） | 避免“现价无摩擦全额成交”的收益虚高 |
| **全额法定规费扣除** | 严格扣除 0.05% 印花税（卖出）、万 2.5 佣金（最低 5 元起收）与过户费 | 确保实盘收益与模拟盘高度拟合 |

## 2. SQLite 多账户账本与审计追踪

模拟交易引擎采用本地 SQLite 数据库独立维护多账户体系：
- 资金账户表：记录可用资金、冻结资金、总资产与最新收益率；
- 持仓明细表：记录个股代码、持股数、可用股数、持仓成本与盈亏；
- 成交流水表：记录每笔买入/卖出成交时间戳、撮合价、数量、规费与滑点成本，支持全流程审计对账。
