# 陈小群战法专有术语与概念表 (Glossary)

本文档定义陈小群交易体系中的核心术语、概念定义与研判标准。

---

## 1. 席位密码 (Seats & Signatures)

- **大连金马路 (中国银河证券股份有限公司大连金马路证券营业部)**：
  陈小群最知名的一战成名招牌席位。特点是极具大局观、擅长在总龙头最脆弱或分歧最大的深水区单笔数千万元甚至上亿元点火扫单、引导回封，并在主升浪中敢于大额锁仓，与市场合力共享超额溢价。
- **大连黄河路 (中国银河证券股份有限公司大连黄河路证券营业部)**：
  陈小群常用协同主账号或马甲席位之一，常与金马路同进同出或交替做T。
- **中信大连分公司 (中信证券股份有限公司大连分公司)**：
  大资金机构化运作席位，常出现在百亿级大成交中军标的的龙虎榜中。
- **席位联动与协同盘**：
  陈小群席位上榜往往伴随着“呼家楼”、“章盟主”、“方新侠”、“炒股养家”等一线顶级游资的合力认可。

## 2. 核心战法术语 (Core Setup Terminology)

- **总龙头 (Market Leader / Soul Stock)**：
  引领全市场情绪周期、成交量最大、人气最高、板块涨跌标杆的灵魂标的（如历史上的浙江建投、中通客车、剑桥科技）。非总龙头不享有市场最强流动性溢价。
- **深水核按钮 (Deep Water Panic Selling)**：
  龙头股票在早盘或盘中遭遇获利盘或恐慌盘疯狂挂跌停价或大单砸盘，股价快速下探至 $-5\%$ 至跌停板附近的极端分歧状态。
- **深水低吸 (Deep Water Dip Buying)**：
  在总龙头被砸入深水、恐慌盘宣泄殆尽时，利用大单承接逆向吸筹，吃足廉价恐慌筹码的手法。
- **地天板 / 大长腿 (Floor-to-Ceiling Limit Up / Long Lower Shadow)**：
  股价从跌停板（或接近跌停）附近被巨额资金撬起拉升直奔涨停板，日内振幅高达 $15\% \sim 20\%$，是情绪发生惊天大逆转的标志。
- **弱转强 (Weak to Strong Transition)**：
  前一日表现极弱（如放量烂板、炸板大回落、跌停）、次日早盘集合竞价或开盘却大幅超预期强势高开高走，主力资金不计成本抢筹的现象。
- **竞价抢筹 (Auction Front-Running)**：
  9:20至9:25分集合竞价期间，红柱成交量急剧放大、买单持续向上扫单，使得开盘价明显脱离前日低迷预期的操盘行为。
- **换手板 (Turnover Limit Up)**：
  股票在涨停前经过充分的分时震荡与换手（日换手率通常在 $15\% \sim 30\%$ 甚至更高），充分洗掉前期获利盘，垫高市场平均成本，有利于后市连续走强。
- **中军大票 (Sector Anchor / Flagship Core)**：
  市值通常在 200 亿以上、每日成交额 20 亿~60 亿的行业或概念绝对核心龙头，流动性极佳，适合超大资金进出（如科大讯飞、剑桥科技、浪潮信息）。
- **龙头首阴 (First Red/Black Breakdown of the Leader)**：
  连板总龙头在连续上涨后，首次出现没有封板并收出长上影或大实体阴线。属于市场第一阶段分歧，往往存在极高胜率的反包博弈机会。
- **反包板 (Engulfing Limit Up)**：
  前一日收阴线或大跌，次日以涨停板的方式直接吞没昨日阴线全部实体，宣告多头重新掌控话语权。
- **二波行情 (Second Wave Impulse)**：
  总龙头在首轮主升后回踩重要均线（5日/10日均线）企稳，筹码沉淀完成后再次放量开启的新一轮主升浪。
