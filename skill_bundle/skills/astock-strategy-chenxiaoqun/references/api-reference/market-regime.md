# 情绪周期与陈小群战法适配矩阵 (Market Regime)

陈小群的出手策略高度依赖于全市场情绪周期。只有在合适的环境下使用正确的模式，才能达到游资的高赔率与高胜率。

---

## 1. 情绪周期四大阶段划分

```
  阶段 1: 混沌/启动期   阶段 2: 发酵/主升期    阶段 3: 高位分歧/震荡期    阶段 4: 退潮/冰点期
        ┌─────┐               ▲                       ▲
        │ 试错 │               │ 锁仓/做T              │ 减仓/防守
  ──────┴─────┴───────────────┴───────────────────────┴─────────────────► 跌停/空仓
                                                      (深水承接/首阴反包)
```

| 情绪阶段 | 市场典型特征 | 陈小群允许的战法 | 仓位约束 |
| :--- | :--- | :--- | :--- |
| **阶段 1：混沌启动期** | 新老题材交替，连板高度压制在3板以下，冰点后第一只破局板出现 | **战法二 (竞价超预期弱转强)**<br>试探性首板/一进二 | 20% ~ 30% 试错仓位 |
| **阶段 2：发酵主升期** | 主线题材明确，总龙头突破连板压制（4连板以上），后排助攻梯队完整，赚钱效应爆棚 | **战法三 (主升中军做T锁仓)**<br>**战法二 (弱转强连续加速)** | 50% ~ 80% 重仓甚至单票格局 |
| **阶段 3：高位分歧期** | 龙头连板首次断板或剧烈振荡，日内炸板率升高，板块分化但中军承接强劲 | **战法一 (深水核按钮低吸)**<br>**战法四 (龙头首阴反包二波)** | 30% ~ 50% 动态机动仓位，快进快出 |
| **阶段 4：退潮冰点期** | 高位连板股大面积跌停（A杀），天地板频现，亏钱效应扩散，昨日涨停指数大幅下跌 | **【全面禁止开新仓】**<br>持有标的严格执行止损线清仓 | **0% 绝对空仓观望** |

---

## 2. 战法总开关机制 (The Master Switch)

任何战法触发前，必须先检验总开关：

1. **总开关开 (Green 🟢)**：
   - 涨跌停比 $> 3:1$；
   - 跌停家数 $< 5$ 家且无无量一字跌停；
   - 主线板块成交额占全市场 $> 10\%$；
   - 允许执行战法一至战法四全部模块。
2. **总开关黄 (Yellow 🟡)**：
   - 市场成交缩量，大盘处于震荡市；
   - 跌停家数在 $5 \sim 15$ 家之间；
   - 仅允许对全市场最高辨识度“唯一总龙头”进行**深水低吸**或**首阴反包**，严禁追高打板后排杂毛。
3. **总开关红 (Red 🔴)**：
   - 出现总龙头直接一字跌停且封死（如前一日买入的标的出现极端负反馈）；
   - 跌停家数 $> 20$ 家；
   - 市场进入亏钱效应退潮期；
   - **绝对禁止开仓，已有持仓执行 T0/T1/T2 止损离场**。
