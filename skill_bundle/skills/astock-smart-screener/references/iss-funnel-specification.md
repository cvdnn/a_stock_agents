# SPEC-ALGO-ISS-001 四阶智能漏斗架构规范 (ISS Funnel Specification)

本文档说明 `astock-smart-screener` 中配置化选股系统的四阶漏斗流水线、条件语法树与模型版本管理。

---

## 2. 条件语法树与模型版本仓库

- **声明式 YAML 配置**：
  模型条件使用统一 YAML 声明，支持 `and`、`or`、`not` 逻辑节点以及比较操作符（`>`, `<`, `in`, `between`）。
- **静态 AST 编译与版本指纹**：
  在执行前，漏斗配置被编译为确定性 AST，并生成唯一的 SHA256 版本哈希（`model_version_sha256`）。
- **T+N 跟踪评估 (Tracking Ledger)**：
  每个交易日产出的入池标的被自动记入持久化跟踪账本，在 T+1、T+3、T+5、T+10 自动回测真实交易表现并计算信息系数（IC）与超额收益。
