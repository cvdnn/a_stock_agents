# 退哥短线交易规则与量化判定库 (Tuige Shortline Rules)

本文档归纳 `astock-tactical-signals` 中退哥短线规则体系的核心买卖点量化条件。底层由 `core/strategy/tuige.py` 提供纯 Python 判定引擎。

---

## 1. 核心交易纪律

1. **先看大盘周期**：大盘退潮期不接力，大盘冰点期不格局，大盘主升期不恐高；
2. **涨停基因**：无涨停不关注，近 20 个交易日内至少具有 1 根实体涨停 K 线；
3. **分时强弱优先**：买在分歧，卖在一致；弱转强次日必须高开并迅速放量上攻；
4. **失效出局绝对果断**：买入逻辑被证伪次日开盘无条件止损，绝不恋战。

---

## 2. 三大核心交易场景与量化判定

### 场景一：涨停回调支撑 (Limit Up Pullback)
- **触发条件**：
  1. 标的近 5 日内曾录得 10% 涨停（双创板 20%）；
  2. 随后经历 1~3 天调整，回调期间成交量必须缩减至涨停日成交量的 50% 以下（缩倍量）；
  3. 回调最低价未跌破涨停阳线实体的一半（或 MA5/MA10 关键均线）；
  4. 企稳当日早盘分时放量翻红。

### 场景二：龙头首阴次日反包 (Leader First Negative)
- **触发条件**：
  1. 标的此前连续涨停板数 $\ge 3$；
  2. 昨日出现首根阴线（未封涨停），但未跌停且换手率未出现天量（换手率 $< 35\%$）；
  3. 今日集合竞价弱转强（平开或高开），9:35 前分时快速拉升突破昨日阴线开盘价。

### 场景三：连板分歧接力 (Relay Breakout)
- **触发条件**：
  1. 处于 1 进 2 或 2 进 3 阶段；
  2. 早盘分时震荡洗盘，量能释放充分后大单封板；
  3. 板上封单金额占流通市值比例 $\ge 3\%$。
