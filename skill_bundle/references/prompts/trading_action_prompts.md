# 盘中实战交易反应动作决策提示词

## 三大场景即时反应动作规则

1. **场景一：开盘冲高 (+2% ~ +5% 以上)**
   - 遇到上方强阻力位（MA20/MA60或前高筹码峰）滞涨时：减仓 1/3 ~ 1/2 锁定利润。
   - 涨停封死且封单量大：持有不动，次日享受溢价。
   - 冲高回落跌破均价线：止盈/减仓剩余仓位。

2. **场景二：盘中窄幅震荡 (-1.5% ~ +1.5%)**
   - 维持底仓，观望不轻易加仓。
   - 围绕分时均价线进行小波段做T（低吸高抛），价差达到 1.5% 以上平仓做T部分。

3. **场景三：盘中急速跳水 / 破位下跌 (-3% ~ -5% 以下)**
   - 触及 T0 警戒线（-3%）：禁止一切抄底和加仓行为，做好减仓准备。
   - 触及 T1 减仓线（-5%）：无条件执行减半仓操作。
   - 触及 T2 绝杀线（-8%）：全部清仓离场，保全本金。
